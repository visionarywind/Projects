# Benchmark 计划

当前目录只记录计划，避免在红黑树删除和不变量尚未充分验证时过早优化。

## 场景

- 随机、递增、递减插入；
- 成功和失败查找；
- 随机删除；
- 交替插入/删除；
- 完整中序遍历；
- 清空容器。

## 对照与记录

至少对照 `std::set<int>`，固定编译器、Release 选项、数据规模、随机 seed、预热和重复次数。记录 CPU、操作系统、是否计入分配、结果校验和中位数/分位数。不能以一次运行证明普遍性能优势。

## 优化顺序

正确性稳定后，依次评估黑色哨兵、热路径和节点布局，再评估 allocator/节点池。每次优化都必须重跑完整 CTest 和 Sanitizer，并保留优化前后可重放的 workload。
