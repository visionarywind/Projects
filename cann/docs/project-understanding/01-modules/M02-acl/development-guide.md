# M02 ACL 开发指南

## 修改前

1. 确认 API 属于 ACL 还是 Runtime 仓，避免跨仓复制实现。
2. 查公共头文件、错误码宏和 CMake 安装目标。
3. 明确句柄所有权、异步生命周期和线程规则。
4. 为参数错误、Runtime 失败和资源清理分别设计测试。

## 修改中

- 保持 `acl*Impl` 的参数检查、日志和 Runtime 错误转换风格。
- 不在 ACL 层绕过 Runtime 直接访问 Driver。
- 不改变 C ABI 结构布局和枚举值；必要时增加而不是重排。
- 每个创建路径配对销毁路径，异常分支也要释放已取得资源。

## 修改后

运行仓库文档中的构建和 UT 入口，并记录工具链、安装路径、设备和测试结果。若未执行或无硬件，明确标注未验证。
