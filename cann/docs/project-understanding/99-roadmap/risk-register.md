# 项目风险登记

- 证据状态：静态分析风险；未将其表述为已验证缺陷

| ID | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | 四仓/Toolkit/Driver/Firmware 版本不配套 | 编译、加载或执行失败 | 固定版本矩阵和发布包 |
| R2 | 异步资源提前释放 | 崩溃、数据损坏 | 明确完成边界并做故障注入 |
| R3 | 错误跨层映射丢上下文 | 定位困难 | 保存原始/映射错误和阶段字段 |
| R4 | ioctl/DMA 用户参数校验不足 | 内核故障或越界 | 边界测试、静态分析和安全拷贝 |
| R5 | 全局锁/缓存与多设备并发 | 死锁、竞态或状态污染 | TSAN、锁顺序文档和压力测试 |
| R6 | SoC 条件编译分支不一致 | 产品特定回归 | 按 SoC 建立构建/设备矩阵 |
| R7 | 无硬件导致错误结论 | 发布风险 | 明确“未验证”，补设备 CI |

来源和详细边界见各模块 `risks-and-debt.md` 与 `90-cross-module/error-boundaries.md`。
