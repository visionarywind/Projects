# AI 辅助软件工程与质量术语表

| 术语 | 含义 | 易混点 |
|---|---|---|
| vibe-coding | 以自然语言和快速反馈驱动编码 | 不等于免审查或无测试 |
| context window | 模型一次可见的上下文范围 | 不等于完整代码库 |
| grounding | 用代码、文档、测试等证据约束生成 | 不等于模型一定正确 |
| tool call | Agent 对外部工具的结构化调用 | 调用成功不等于业务成功 |
| oracle | 判断测试结果正确与否的准则 | 不等于“程序未报错” |
| graph break | Agent/编译/流程无法继续自动化的边界 | 需要定义回退和人工接管 |
| quality gate | 阻断不满足规则的变更门禁 | 不等同于单一 lint |
| provenance | 代码、依赖、数据和决策的来源链 | 不等同于 Git 提交号 |
