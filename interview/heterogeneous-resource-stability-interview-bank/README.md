# 异构资源稳定性专家级面试题库

本题库面向 CPU、GPU、NPU 等异构计算系统中的资源稳定性问题，训练学习者从概念解释逐步达到生产系统设计、故障排查、容量规划和演进决策能力。

## 当前配置

| 配置项 | 值 |
|---|---|
| 目标读者 | 希望系统掌握异构资源稳定性的技术学习者 |
| 适用场景 | 技术面试、系统设计面试、源码面试和综合面试 |
| 题目规模 | 入门、中级、高级、专家各 100 题，共 400 题 |
| 输出语言 | 中文 |
| 当前交付 | 四级题目正文已交付；每级 100 题，共 400 题；进入证据和语义审计阶段 |
| 资料基线 | 本仓库 CANN 项目理解文档；跨平台事实按证据状态标注 |
| 实验权限 | 不执行硬件、网络、RDMA、多进程或高成本实验；方案标为 `[待验证]` |

## 范围与边界

题库聚焦异构设备资源的发现、能力协商、上下文和执行队列、内存与内存池、异步完成、调度隔离、数据传输、跨设备通信、错误传播、恢复降级、观测、性能容量、版本兼容和生产治理。CANN 的 GE/ACL/Runtime/Driver 分层是主要源码证据基座；CUDA、MUSA、ROCm 等只用于解释通用概念或对比，不把不同实现的行为混为一谈。

不把特定厂商的 undocumented 行为、未运行的性能数字、硬件兼容性和历史事故写成普遍事实。没有目标版本或硬件运行记录时，相关内容使用 `[推断]`、`[建议]` 或 `[待验证]`。

## ID 规则

- `HRS-B001`–`HRS-B100`：入门级；
- `HRS-I001`–`HRS-I100`：中等级；
- `HRS-A001`–`HRS-A100`：高级；
- `HRS-E001`–`HRS-E100`：专家级。

ID 一经分配不回收、不重排。每题至少关联一个知识域、一个能力和一种题型，并记录前置题、后续题及证据状态。

## 推荐阅读顺序

先读领域总览、术语表和知识地图，再按 B → I → A → E 学习。每道题先限时口述，再画图、写伪代码、回答追问，最后完成验证练习。高级和专家题要额外写出假设、数量级、失败模式、恢复边界和迁移路径。

## 证据约定

`[已确认]` 表示目标资料直接支持；`[推断]` 表示由多个证据推导；`[待验证]` 表示需要硬件、网络、压测或运行实验；`[建议]` 表示设计建议；`[存在争议]` 表示版本或实现间不一致。源码路径和行号只在核实后使用。
