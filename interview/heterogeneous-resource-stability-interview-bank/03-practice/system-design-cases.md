# 系统设计案例

## 案例 1：多类型加速器统一准入层

设计一个同时管理 CPU/GPU/NPU 的任务准入层。必须澄清能力快照、版本矩阵、拓扑、内存预算、租户配额、故障域、降级策略、观测字段和回滚条件。不可把同名 API 当作同一语义。

## 案例 2：异步任务资源安全层

设计 Context/Stream/Queue、Memory、Event 和任务之间的生命周期管理。必须覆盖 pending task、超时、取消、进程崩溃、引用计数、幂等清理和设备 reset 的未知状态。

## 案例 3：跨节点异构通信的部分失败恢复

设计集合通信和 RDMA 故障下的检测、隔离、重建、重试和服务降级。必须说明参与者一致性、超时边界、故障域、数据正确性 oracle 和成本。

## 案例 4：资源水位和 SLO 驱动的降级

设计显存/内存/队列/带宽水位监控，定义 P99、成功率、恢复时间和错误预算，并比较限流、排队、迁移、精度降低和功能关闭的代价。

以上案例均为设计练习，不是当前系统已有能力；真实方案和性能必须在目标环境验证。
