# 专家能力自检

- [ ] 能从第一性原理定义稳定性和完成边界。
- [ ] 能画出跨 API、Runtime、Driver、设备的调用和资源流。
- [ ] 能区分静态能力、动态资源和拓扑故障域。
- [ ] 能为 Context、Stream、Memory 和任务定义状态机与不变量。
- [ ] 能处理 UNKNOWN、部分失败、取消、重试、恢复和回滚。
- [ ] 能用指标、日志、Tracing、dump 和 oracle 证明结论。
- [ ] 能建立吞吐、尾延迟、容量、碎片和成本模型。
- [ ] 能比较限流、迁移、排队、降级和扩容的短长期代价。
- [ ] 能设计灰度、兼容矩阵、灾备和版本演进路线。
- [ ] 能指出哪些结论只是推断或待验证，而非假装确定。
