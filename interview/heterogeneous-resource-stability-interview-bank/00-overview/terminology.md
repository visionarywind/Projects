# 术语表

| 术语 | 本题库中的工作定义 | 易混边界 |
|---|---|---|
| 异构资源 | 不同处理器、设备内存、执行队列、互联链路及其软件控制面组成的资源集合 | 不只指多种芯片，也包含同一设备上的不同资源池和故障域 |
| 稳定性 | 在约束和局部失败下保持正确、可用、资源安全、可恢复和可诊断 | 不是单纯不崩溃，也不是单一延迟指标 |
| Device | 可被 Runtime/Driver 识别并执行任务的设备实例 | 设备编号不等于设备已具备当前任务所需能力 |
| Context | 将线程、设备、资源和任务关联起来的执行环境 | 不等于设备本身；不同实现的主/显式 Context 语义不同 |
| Stream / Queue | 表示提交顺序、依赖或调度通道的执行对象 | 提交成功不等于设备已完成；Stream 不必等价于硬件队列 |
| Event | 用于记录或等待某个执行边界的同步对象 | Event 完成语义须以目标 Runtime 文档和实现为准 |
| Host memory | CPU 地址空间中的内存 | 可被设备访问不等于普通 host 指针天然 DMA 安全 |
| Pinned/registered memory | 为设备传输固定或注册的主机内存 | pin、map、location 和生命周期是不同状态 |
| Device memory | 设备可直接访问的地址空间或其 backing | 虚拟地址、物理 backing、池中缓存段不可混称 |
| P2P | 设备之间直接或经互联访问/传输数据的能力 | 能枚举两设备不代表当前拓扑、权限和版本都支持 P2P |
| DMA | 设备或控制器在不由 CPU 逐字节搬运的情况下传输数据 | DMA 提交、传输完成和主机可见性是不同边界 |
| 故障域 | 一个故障可能同时影响的资源范围，如进程、设备、节点或网络 | 恢复粒度不能大于故障域而不引入级联影响 |
| 降级 | 主动降低并发、精度、功能或资源占用以保持核心服务 | 降级必须有触发条件、可观测信号和恢复条件 |
| SLO | 对可用性、延迟、正确率等服务目标的约束 | SLO 不是一次压测结果，也不自动说明根因 |
| `[已确认]` | 目标资料直接陈述或本次实验直接观察 | 仍需限定版本和环境 |
| `[推断]` | 由多个证据合理推出但未直接陈述 | 不得写成源码明文行为 |
| `[待验证]` | 需要目标硬件、驱动、网络、压测或动态实验 | 必须提供输入、步骤和 oracle，而不是虚构结果 |
| `[建议]` | 面向设计改进的方案 | 不表示当前系统已有该能力 |
