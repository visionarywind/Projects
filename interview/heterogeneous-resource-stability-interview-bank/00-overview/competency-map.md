# 能力地图：异构资源稳定性

| 能力 ID | 能力 | 入门表现 | 中级表现 | 高级/专家表现 |
|---|---|---|---|---|
| C01 | 概念解释 | 区分设备、内存、队列和稳定性指标 | 解释边界及反例 | 从第一性原理定义不变量和适用域 |
| C02 | 原理推导 | 写出简单生命周期或容量关系 | 追踪状态、因果和复杂度 | 定量分析上限、故障概率与二阶影响 |
| C03 | 流程追踪 | 画出 API 到设备的主线 | 找到分派、转换和完成边界 | 处理动态分派、异步回调和跨故障域路径 |
| C04 | 实现分析 | 读懂句柄、伪代码和配置 | 设计资源管理和 focused test | 评审并发安全、回滚和兼容实现 |
| C05 | 测试验证 | 给出正常/异常输入和 oracle | 设计集成、性能和故障注入 | 建立不变量、统计置信度和验收门槛 |
| C06 | 故障排查 | 按现象分类并保留错误码 | 用证据排除假设、恢复服务 | 处理部分失败、级联故障、复盘和治理 |
| C07 | 性能/容量 | 认识吞吐、延迟和显存 | 定位瓶颈并比较方案 | 做容量模型、成本决策和退化设计 |
| C08 | 工程设计与专家判断 | 说明基本取舍 | 在约束下给出可实施架构 | 设计迁移、灰度、回滚和组织级标准 |

## 评分侧重

B 级优先 C01–C03；I 级增加 C04–C06；A 级要求 C05–C08 的量化约束；E 级要求证据、反例、状态机、失败模式和长期演进同时成立。回答不能用“加监控”“重试一下”“换更大设备”等口号替代因果和验证。
