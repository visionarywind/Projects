# PyTorch 领域总览

## 边界

题库覆盖从 Python 张量 API 到训练运行时、自动微分、`nn.Module`、数据管道、优化器、混合精度、分布式训练、`torch.compile`、性能分析、序列化/部署和 C++/CUDA 扩展。具体模型架构、上层训练框架和推理服务只在它们直接影响 PyTorch 行为时纳入。

## 目标读者

默认面向后端/算法/深度学习工程师、框架工程师和准备 PyTorch 源码或系统设计面试的候选人。题目从可运行的最小示例递进到生产系统的容量、可靠性和演进决策。

## 先修知识

Python、线性代数、概率与微积分基础；基本数据结构、并发、操作系统、网络和 GPU 编程概念。没有相关先修知识时，先完成入门级题目的背景部分和实践路线。

## 版本边界

主版本基线：PyTorch `v2.14.0`。涉及旧版本、 nightly、后端差异或第三方扩展时，必须明确版本和适用条件。
