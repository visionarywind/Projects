## 1. 题目与约束

给定整数数组 `nums` 和整数 `k`，返回出现频率最高的 `k` 个元素。若频率相同，输出顺序不限。

约束：`1 <= k <= 不同元素个数`；数组长度可达 `10^5` 或更高。 本题按专家追问处理：先澄清输入规模、在线/离线、是否允许修改数据、并发或持久化要求，再给出可验证方案。

## 2. 面试思路

统计频率后对所有不同元素按频率完整排序是 `O(m log m)`，当只需要 TopK 时可进一步优化。

优化切入点：维护大小为 `k` 的小根堆，堆顶是当前 TopK 中频率最低者；新元素频率更高时替换堆顶。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：先用哈希表统计频率，再遍历频率表维护小根堆 `(freq,value)`。堆大小超过 `k` 时弹出堆顶，最后堆中元素即答案。

正确性说明：堆中始终保存已处理元素中的 `k` 个最高频候选。若新元素未进入堆，说明其频率不高于当前第 k 高频；若进入并弹出最小频率者，则剩余仍是最高的 k 个。归纳到所有元素处理完，堆即全局 TopK。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> solve(vector<int> nums, int k) {
    unordered_map<int, int> freq;
    for (int x : nums) freq[x]++;
    using P = pair<int,int>; // {frequency, value}
    priority_queue<P, vector<P>, greater<P>> pq;
    for (auto [value, f] : freq) {
        pq.push({f, value});
        if ((int)pq.size() > k) pq.pop();
    }
    vector<int> ans;
    while (!pq.empty()) { ans.push_back(pq.top().second); pq.pop(); }
    reverse(ans.begin(), ans.end());
    return ans;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

## 5. 复杂度

统计 `O(n)`，堆维护 `O(m log k)`，空间 `O(m+k)`，其中 `m` 是不同元素个数。 复杂度成立的前提是输入满足题目约束；如果输出本身很大，需要把输出规模计入空间和时间。
