## 1. 题目与约束

给定整数数组 `nums` 和目标值 `target`，返回两个不同下标，使得两个元素之和等于 `target`。若不存在答案，返回空数组。

约束：`2 <= nums.size() <= 10^5`，元素可为负数、0 或正数；同一元素不能使用两次。 本题按专家追问处理：先澄清输入规模、在线/离线、是否允许修改数据、并发或持久化要求，再给出可验证方案。

## 2. 面试思路

暴力做法枚举所有二元组，时间复杂度 `O(n^2)`，大输入下不可接受。

优化切入点：扫描到当前元素 `x` 时，只需要知道历史元素中是否存在 `target - x`。哈希表能把“查找历史补数”降到平均 `O(1)`。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：从左到右遍历数组；对每个 `nums[i]`，先查哈希表中是否有补数，再把当前值和下标放入哈希表。先查后插入可以避免复用同一元素。

正确性说明：循环不变量是：处理下标 `i` 前，哈希表保存所有下标小于 `i` 的元素及其一个下标。若答案右端点为 `i`，左端点必在哈希表中，因此算法会发现；若未发现，则不存在以 `i` 为右端点的合法答案。遍历结束后所有右端点都被检查，所以算法正确。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> solve(vector<int> nums, int target) {
    unordered_map<int, int> pos;
    pos.reserve(nums.size() * 2);
    for (int i = 0; i < (int)nums.size(); ++i) {
        int need = target - nums[i];
        auto it = pos.find(need);
        if (it != pos.end()) return {it->second, i};
        pos[nums[i]] = i;
    }
    return {};
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。
