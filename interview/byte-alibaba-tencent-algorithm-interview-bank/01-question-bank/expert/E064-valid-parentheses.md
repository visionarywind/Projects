## 1. 题目与约束

给定只包含 `()[]{}` 的字符串，判断括号是否按类型和嵌套顺序正确匹配。

约束：`0 <= s.length <= 10^5`；空串通常视为有效。 本题按专家追问处理：先澄清输入规模、在线/离线、是否允许修改数据、并发或持久化要求，再给出可验证方案。

## 2. 面试思路

只统计左右括号数量无法判断嵌套顺序，例如 `([)]` 数量正确但无效。

优化切入点：最近打开的括号必须最先关闭，这是后进先出结构，使用栈保存未匹配左括号。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：扫描字符；左括号入栈；右括号要求栈非空且栈顶类型匹配，然后弹出；结束时栈为空才有效。

正确性说明：栈始终保存当前前缀中尚未匹配的左括号，栈顶是最近的未闭合括号。合法字符串的每个右括号只能匹配该栈顶；若不匹配或栈空，任何重排都无法修复当前前缀。扫描结束栈空等价于所有左括号被匹配。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

bool solve(string s) {
    vector<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push_back(c);
        else {
            if (st.empty()) return false;
            char o = st.back(); st.pop_back();
            if ((c == ')' && o != '(') || (c == ']' && o != '[') || (c == '}' && o != '{')) return false;
        }
    }
    return st.empty();
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

`{[()]}` 依次入栈 `{ [ (`，随后 `)`、`]`、`}` 依次匹配栈顶，最终栈空，返回 true。
