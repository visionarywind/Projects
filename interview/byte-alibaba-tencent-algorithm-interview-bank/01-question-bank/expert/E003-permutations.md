## 1. 题目与约束

给定不含重复元素的整数数组 `nums`，返回其所有全排列。扩展一：数组可能含重复元素，要求返回不重复的排列。扩展二：不枚举全部，而是求字典序第 K 个排列。

约束：`1 <= nums.size() <= 8`（完整枚举时结果有 n! 个，n=8 为 40320，n=12 约 4.79 亿，输出已不可承受）；扩展题 `1 <= n <= 9` 求第 K 个排列（K 可到 n!）；元素值范围 `[-10,10]`。

专家要求：给出含重复元素去重的正确性论证；区分“按任意顺序枚举”和“按字典序枚举”；用输出规模下界论证枚举类问题不可能更优。

## 2. 面试思路

- 回溯的核心是“决策树”：第 i 层选一个尚未使用的元素放到位置 i，枚举所有选择即得到所有排列。
- 两条常见路径：
  1. **used 数组 + 排序去重**：语义清晰、易证明、去重稳定；
  2. **交换法（原地）**：无需 used 数组，额外空间更小，但含重复元素时去重更容易写错。
- 需要字典序时两条路：排序后用 `std::next_permutation`，或用康托展开（阶乘进制）直接定位第 K 个，避免生成全部。
- 关键权衡：枚举所有排列必然是 Θ(n·n!)，无法通过剪枝降低输出总量；真正的优化点是“不生成全部”（求第 K 个、只计数、按需生成）。

## 3. 算法与正确性

回溯（used 数组）：

- 递归参数：当前深度 `d`、已用标记 `used`、当前路径 `path`。
- 终止：`d == n` 时输出 `path`。
- 转移：遍历每个 `i`，若 `used[i]` 跳过；若与去重条件冲突跳过；否则标记、入路径、递归、回溯。

去重条件（先排序）：`if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;`

含义：同一层中，相同的值只允许由“第一个尚未使用的”那个元素承担，从而避免把相同值放到同一位置而产生重复分支。

正确性（去重）：

- 完备性：任意一个不重复排列 P，都能沿“每次选择等于 P[d] 的、尚未使用的最靠前元素”这条路径生成，故 P 一定被输出。
- 无重复性：假设同一排列被两条路径生成，则它们首次分歧于第 d 层选择了两个下标 `i < j`，且 `nums[i] == nums[j]`。分歧前两条路径的选择相同，所以此时 `i` 尚未被使用。由去重条件，选择 `j` 的分支会被跳过，矛盾。故输出无重复。
- 综合两点，输出恰为所有不同排列。

枚举顺序：若 `nums` 已排序且按 `i` 递增递归，则收集顺序即字典序。

## 4. C++17 实现

含重复元素的回溯（主实现）：

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> permuteUnique(vector<int> nums) {
    sort(nums.begin(), nums.end());
    int n = (int)nums.size();
    vector<vector<int>> res;
    vector<int> path;
    vector<char> used(n, 0);
    path.reserve(n);

    function<void()> dfs = [&]() {
        if ((int)path.size() == n) {
            res.push_back(path);
            return;
        }
        for (int i = 0; i < n; ++i) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;   // 同层去重
            used[i] = 1;
            path.push_back(nums[i]);
            dfs();
            path.pop_back();
            used[i] = 0;
        }
    };
    dfs();
    return res;
}
```

字典序枚举（排序 + `next_permutation`）：

```cpp
vector<vector<int>> permuteLex(vector<int> nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> res;
    do {
        res.push_back(nums);
    } while (next_permutation(nums.begin(), nums.end()));
    return res;
}
```

第 K 个字典序排列（康托展开的逆，等价于阶乘进制）：

```cpp
string kthPermutation(int n, int k) {        // 序列 1..n，k 从 1 开始
    vector<long long> fact(n + 1, 1);
    for (int i = 1; i <= n; ++i) fact[i] = fact[i - 1] * i;
    if (k < 1 || k > fact[n]) return "";
    vector<int> digits(n);
    iota(digits.begin(), digits.end(), 1);
    --k;                                     // 转为 0-based
    string res;
    res.reserve(n);
    for (int i = n; i >= 1; --i) {
        int idx = (int)(k / fact[i - 1]);
        k %= fact[i - 1];
        res.push_back(char('0' + digits[idx]));
        digits.erase(digits.begin() + idx);   // O(n)
    }
    return res;
}
```

`digits.erase` 为 O(n)，整体 O(n²)；若用 Fenwick 树按排名查询第 `idx` 个可用数字，可降到 O(n log n)。

## 5. 复杂度

- 回溯枚举：无重复时结果数为 n!，每个结果复制长度为 n，故时间 Θ(n·n!)；递归深度 O(n)；除输出外辅助空间 O(n)。
- 含重复元素时结果数 = n! / Π(c_v!)，其中 c_v 为值 v 的出现次数（多重集排列数），时间与之成比例。
- `next_permutation` 枚举：共 n! 次调用，单次最坏 O(n)，含输出整体 Θ(n·n!)；遍历全程的交换总次数约为 n! 量级，均摊每次接近 O(1)。
- 第 K 个排列：朴素 O(n²)；Fenwick 优化 O(n log n)。`fact[n]` 需用 64 位，n≥21 时超出 `int64` 表示范围。
- 只计数（不枚举）：答案 = n! / Π(c_v!)，O(n)。

**下界论证**：完整枚举的输出本身含 Θ(n·n!) 个整数，故不存在渐进更快的算法；优化只能发生在“不输出全部”的变体上。

## 6. 例子推演

`nums=[1,1,2]`，排序后为 `[1,1,2]`：

| 层 | 选择 | 说明 |
|---|---|---|
| 0 | i=0(1) | used[0]=1 |
| 1 | i=0 跳过；i=1(1) 允许，因 `nums[1]==nums[0]` 但 used[0]==1 | path=[1,1] |
| 2 | i=2(2) | path=[1,1,2] → 输出 |
| 1 | i=2(2) | path=[1,2] |
| 2 | i=0(1) | path=[1,2,1] → 输出 |
| 0 | i=1 跳过（`nums[1]==nums[0]` 且 `!used[0]`） | 避免重复分支 |
| 0 | i=2(2) | path=[2] |
| 1 | i=0(1) | path=[2,1] |
| 2 | i=1(1) 允许 | path=[2,1,1] → 输出 |

结果：`[[1,1,2],[1,2,1],[2,1,1]]`，共 3 = 3!/(2!·1!) 个，无重复。

第 K 个（n=3, k=4，序列 1..3）：

- `fact = [1,1,2,6]`，`k-1=3`。
- i=3：`idx = 3/2 = 1`，取 `digits[1]=2`，`k = 3%2 = 1`，`digits=[1,3]`。
- i=2：`idx = 1/1 = 1`，取 `digits[1]=3`，`k = 0`，`digits=[1]`。
- i=1：`idx = 0`，取 1。
- 结果 `"231"`。字典序枚举 1..3 为 123, 132, 213, 231, 312, 321，第 4 个正是 231。

## 7. 测试与调试

- 边界：单元素 `[1]`；两元素含重复 `[1,1]`；全相同 `[2,2,2]` 只有 1 个排列。
- 验证结果数与 n!/Π(c_v!) 一致，且无重复（用 set 去重后比较大小）。
- 对 `next_permutation` 版与回溯版做差分：排序后两者输出应逐元素相同。
- 第 K 个排列：暴力枚举全部并排序，取第 k 个作 oracle，遍历 k=1..n!。
- 调试：打印每层选择与 `used`，重点检查去重条件是否误杀了合法分支。

## 8. 面试追问

1. **如何求字典序第 K 个排列？** 用阶乘进制（康托展开的逆）：从高位起，用 `k / (剩余位数-1)!` 确定该位在剩余可用数字中的排名，再更新 k。给出 O(n²)（或 Fenwick 树 O(n log n)）实现，并说明 K 的 1-based/0-based 差异与阶乘溢出。
2. **如何按字典序枚举而不先生成全部再排序？** 先对输入排序，再用 `std::next_permutation` 逐个生成；它按字典序、并自动跳过重复排列。若只要第 K 个，可直接定位，跳过不必要的枚举。
3. **若只问“有多少个不同排列”或“含重复元素的下一个排列”？** 计数 = n!/Π(c_v!)，用 64 位并注意溢出；“下一个排列”可在含重复的序列上调用 `next_permutation`，其前提是理解它“从中后段找第一个升序对并交换、再反转后缀”的不变式。

## 9. 易错点与反例

- **反例（去重写错）**：条件写成 `if (i>0 && nums[i]==nums[i-1]) continue;` 会漏掉合法分支：`[1,1]` 将得不到任何排列。必须附加 `&& !used[i-1]`。
- **反例（交换法去重）**：交换法若不做同层去重，`[1,1,2]` 会输出重复的排列。交换法去重需 `if (i>start && a[i]==a[start]) continue;`，且要理解 `a[start]` 在交换过程中会变化，判断时容易出错。
- **易错**：`res` 中存 `path` 的引用或指针而非拷贝，回溯后内容被修改。
- **易错**：第 K 个排列忘记把 k 减一（转 0-based），整体偏移一位。
- **易错**：`next_permutation` 前未排序，输出不是完整的字典序（它只枚举当前排列之后的排列）。
- **易错**：阶乘用 `int` 计算，n≥13 时溢出。

## 10. 变体与迁移

- 结构迁移：子集枚举、组合枚举、含重复元素的组合（组合去重条件与排列不同）、N 皇后（回溯 + 剪枝）。
- 剪枝迁移：在排列决策树中按前缀计数或按字典序提前返回（求第 K 个），把 Θ(n·n!) 降到 O(n²) 或 O(n log n)。
- 算法迁移：康托展开用于“排列的名次”“逆序对计数”“状态压缩编码”；`next_permutation` 的不变式用于“下一个排列”单题。
- 约束迁移：一旦要求“返回全部”，复杂度下界被锁死；一旦改为“计数 / 第 K 个 / 按需生成”，复杂度量级骤降。这种取舍是专家题最常考的点。
