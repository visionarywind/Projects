## 1. 题目与约束

一次可以爬 1 级或 2 级台阶，问爬到第 `n` 级共有多少种不同的走法。

约束：`1 <= n <= 45`。答案在 `int` 范围内（`f(45) = 1836311903 < 2^31 - 1`）。入门版本只问方案数，不问具体路径。若 `n` 更大（如 `n <= 10^9`）则必须搭配取模与矩阵快速幂，见第 8、10 节。

## 2. 面试思路

先给暴力：直接递归枚举每一步走 1 还是 2，叶子结点是方案数，时间复杂度约为 `O(f(n))` 即指数级，`n=45` 时不可接受，且存在大量重复子问题，需要画递归树暴露这一点。

优化切入点：设 `f(n)` 为跳到第 `n` 级的方案数。最后一步只能来自第 `n-1` 级（走 1 级）或第 `n-2` 级（走 2 级），且这两类方案集合互不相交、并集覆盖全部方案。于是 `f(n) = f(n-1) + f(n-2)`。

面试表达顺序建议：**先写暴力建立直觉 → 定义状态与转移 → 说明重叠子问题与无后效性 → 用滚动变量压缩空间 → 最后讨论大 `n` 的进阶做法**。

## 3. 算法与正确性

递推：`f(1) = 1`，`f(2) = 2`，对 `n >= 3`，`f(n) = f(n-1) + f(n-2)`。

**状态定义**：`f(k)` 表示爬到第 `k` 级的方案总数。

**递推（转移）**：任何一条到第 `n` 级的路径，其倒数第二步必然停在第 `n-1` 级或第 `n-2` 级；来自 `n-1` 的路径集合与来自 `n-2` 的路径集合不相交（末步长度不同），合并即为全部。故 `f(n) = f(n-1) + f(n-2)`。

**循环不变量**：在第 `i` 轮迭代开始时，变量 `a = f(i-2)`，`b = f(i-1)`（取 `i >= 3`）。每轮执行 `c = a + b`、`a = b`、`b = c` 之后，不变量对 `i+1` 继续成立。

**正确性论证（归纳）**：基础情形 `f(1)=1`、`f(2)=2` 可直接枚举验证。归纳步：假设 `f(i-1)` 与 `f(i-2)` 均正确，由转移得 `f(i) = f(i-1) + f(i-2)`，不变量保证迭代过程中使用的两个量始终是正确的前两项。因此循环结束时 `b = f(n)`，返回正确。

**无后效性**：`f(k)` 只依赖 `f(k-1)`、`f(k-2)`，与更早的走法细节无关，故可自底向上递推。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int climbStairs(int n) {
    if (n <= 0) return 0;          // 边界：无台阶，定义为 0 种
    if (n == 1) return 1;          // 边界：只有 1 级
    if (n == 2) return 2;          // 边界：1+1 或 2
    long long a = 1, b = 2;        // a = f(i-2), b = f(i-1)，从 i=3 起
    for (int i = 3; i <= n; ++i) {
        long long c = a + b;
        a = b;
        b = c;
    }
    return (int)b;
}
```

实现细节：`n <= 2` 直接返回，避免循环边界写错；用 `long long` 累加以防中间和溢出（本范围内不会溢出，但作为防御性写法）；滚动变量 `a, b` 把空间压到 `O(1)`。若 OJ 要求 `class Solution`，把函数移入类中即可。

## 5. 复杂度

- 时间：`O(n)`（单层循环，每次常数次加法与赋值）。
- 空间：`O(1)`（仅用两个标量 `a, b`）；若用数组存 `dp` 则为 `O(n)`。
- 关键前提：状态只用前两项；若转移需要更长的历史窗口（如一次可走 `k` 级），空间需相应增加。

## 6. 例子推演

`n = 5`：

| i | a = f(i-2) | b = f(i-1) | c = a+b = f(i) |
|---|---|---|---|
| 初始 | f(1)=1 | f(2)=2 | — |
| 3 | 1 | 2 | 3 |
| 4 | 2 | 3 | 5 |
| 5 | 3 | 5 | 8 |

返回 `b = 8`。校验：`f(1)=1, f(2)=2, f(3)=3, f(4)=5, f(5)=8`，即斐波那契偏移序列。

边界推演 `n = 1`：直接返回 1。`n = 2`：返回 2（走法为 `1+1`、`2`）。

调试切入点：与暴力递归（或记忆化版本）做差分测试，随机取 `n∈[1,45]` 比较结果；若输出与预期差 1，检查是否漏掉 `f(2)` 的基础情形。

## 8. 面试追问

1. **若 `n` 很大（如 `10^9`）且要求对 `10^9+7` 取模？** 用矩阵快速幂把转移写成 `[[f(n)],[f(n-1)]] = M^(n-1) [[f(2)],[f(1)]]`，`M = [[1,1],[1,0]]`，时间复杂度 `O(log n)`。
2. **若一次可以走 1..k 级？** 转移变为 `f(n) = Σ_{j=1}^{k} f(n-j)`；可用滑动窗口维护前 `k` 项和，时间 `O(n)`、空间 `O(k)`。
3. **若要求输出所有具体路径而非方案数？** 需要回溯枚举，输出规模本身是指数级的，复杂度下界受输出规模约束，不能再用 `O(n)` 递推。

## 9. 易错点与反例

- **反例**：把基础情形写成 `f(1)=1, f(2)=1`，则 `f(3)=2`（少算了 `2+1` 这类），整体偏移一位——错误。正确是 `f(2)=2`。
- **易错**：循环从 `i=1` 或 `i=2` 起跑，导致基础情形被重复累加或 `a, b` 初值错位。
- **易错**：`n` 较大时用 `int` 存中间和，符号位溢出（本题范围安全，但替换成更大 `n` 时需改 `long long` 或取模）。
- **易错**：把"走 1/2 级"当成组合问题直接套 `C(n, k)`，忽略顺序区别（走法是有序序列）。

## 10. 变体与迁移

- 同域迁移：斐波那契数列第 `n` 项（递推形式完全一致，仅偏移不同）。
- 结构迁移：打家劫舍（`f(i) = max(f(i-1), f(i-2) + a[i])`，同样只看前两项的线性 DP）。
- 约束迁移：`n` 增大到 `10^9` 时引入矩阵快速幂；允许走 `1..k` 级时引入滑窗前缀和；要求输出路径时退化为回溯搜索。
