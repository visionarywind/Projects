## 1. 题目与约束

给定字符串 `s`，返回不含重复字符的最长连续子串长度。

约束：`0 <= s.length <= 10^5`；字符集可按 ASCII 或 Unicode 简化为字节处理，面试中需先确认。 本题采用标准约束，重点是把模式讲清楚并写出无明显边界错误的实现。

## 2. 面试思路

枚举所有子串并检查重复字符，最坏 `O(n^3)`；即使增量检查也通常是 `O(n^2)`。

优化切入点：窗口右端右移时，若字符重复，只需要把左端移动到该字符上次出现位置之后；左端不会回退。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：用 `last[c]` 记录字符上次出现下标，维护窗口左端 `left`。遍历右端 `right`，若 `last[s[right]] >= left`，更新 `left = last[s[right]] + 1`，再更新答案。

正确性说明：不变量：每轮更新后 `[left,right]` 不含重复字符，并且是在当前右端下满足条件的最左合法窗口。遇到重复字符时，任何左端不超过上次出现位置的窗口都非法，因此移动到后一位是必要且充分的。所有右端都被枚举，所以最大值正确。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve(string s) {
    vector<int> last(256, -1);
    int left = 0, ans = 0;
    for (int right = 0; right < (int)s.size(); ++right) {
        unsigned char c = (unsigned char)s[right];
        if (last[c] >= left) left = last[c] + 1;
        last[c] = right;
        ans = max(ans, right - left + 1);
    }
    return ans;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

## 5. 复杂度

时间 `O(n)`，空间 `O(|字符集|)`；若使用哈希表则空间与出现字符数相关。 复杂度成立的前提是输入满足题目约束；如果输出本身很大，需要把输出规模计入空间和时间。
