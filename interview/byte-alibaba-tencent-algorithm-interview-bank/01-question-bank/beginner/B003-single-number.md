## 1. 题目与约束

给定非空整数数组，除某个元素只出现一次外，其余元素都恰好出现两次，找出这个只出现一次的元素。

约束：`1 <= nums.size() <= 3·10^4`；每个元素出现 1 次或 2 次；要求线性时间复杂度、常数额外空间（这是本题的考点，暴力计数或哈希表虽正确但不满足空间要求）。元素可为负、零或正。

## 2. 面试思路

先给暴力：用哈希表统计频次再找计数为 1 的元素，时间 `O(n)`、空间 `O(n)`，能通过但要主动指出空间不达标。

优化切入点：异或（XOR）有两个关键性质——`a ^ a = 0`、`a ^ 0 = a`，且满足交换律与结合律。把整个数组全部异或起来，成对的元素两两抵消为 0，最后剩下的正是那个"孤元素"。

面试表达顺序建议：**先写哈希计数版 → 指出空间瓶颈 → 引入异或并说明为什么会成对抵消 → 收尾强调"线性 + 常数空间"这一验收条件**。

## 3. 算法与正确性

步骤：令 `acc = 0`，从左到右遍历数组，执行 `acc ^= nums[i]`，遍历结束后返回 `acc`。

**异或的性质（前提）**：对任意整数 `a, b, c`，有 `a ^ a = 0`、`a ^ 0 = a`、`a ^ b = b ^ a`（交换律）、`(a ^ b) ^ c = a ^ (b ^ c)`（结合律）。

**正确性论证**：设孤元素为 `x`，其余元素成对出现。由交换律与结合律，全部异或的结果可重排为 `x ^ (p1 ^ p1) ^ (p2 ^ p2) ^ ... ^ (pk ^ pk)`，其中每个 `pi` 出现两次。每个 `pi ^ pi = 0`，于是中括号部分整体为 0，最终结果为 `x ^ 0 = x`。故返回值为孤元素，且与元素顺序无关。

**循环不变量**：第 `i` 轮开始前，`acc` 等于前缀 `nums[0..i-1]` 全部元素的异或；每轮 `acc ^= nums[i]` 后不变量对下一轮成立，归纳可得遍历结束时 `acc` 等于全体异或。

**正确性保证**：交换律与结合律确保重排合法，与奇偶抵消无关顺序。这一性质正是"每个成对出现元素贡献 2 次异或、成对抵消"的形式化表达。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int singleNumber(vector<int>& nums) {
    int acc = 0;                       // 单位元：0，因为 a ^ 0 = a
    for (int x : nums) {
        acc ^= x;                      // 成对元素两两抵消
    }
    return acc;
}
```

实现细节：`acc` 初值必须是 0（异或的单位元）；`int` 与本题范围匹配，若元素为 64 位整数需改用 `long long`；负数在补码表示下位模式固定，异或性质依然成立，无需特殊处理。若 OJ 要求 `class Solution`，把函数移入类中即可。

## 5. 复杂度

- 时间：`O(n)`（单次遍历，每次一次异或）。
- 空间：`O(1)`（仅一个累加变量 `acc`）。
- 关键前提：其余元素恰好出现偶数次（本题为 2 次）；异或的交换律与结合律成立。若出现次数不是偶数，结论不再成立，需改用其他方法（见第 10 节）。

## 6. 例子推演

`nums = [4, 1, 2, 1, 2]`：

| i | nums[i] | acc（异或后） |
|---|---|---|
| 初始 | — | 0 |
| 0 | 4 | 0 ^ 4 = 4 |
| 1 | 1 | 4 ^ 1 = 5 |
| 2 | 2 | 5 ^ 2 = 7 |
| 3 | 1 | 7 ^ 1 = 6 |
| 4 | 2 | 6 ^ 2 = 4 |

返回 4，正是只出现一次的元素。可重排验证：`(1^1) ^ (2^2) ^ 4 = 0 ^ 0 ^ 4 = 4`。

边界样例 `nums = [7]`：`acc = 0 ^ 7 = 7`，返回 7。

## 7. 测试与调试

建议用例：
- `[2,2,1]`：期望 1，孤元素在末尾，验证基础抵消；
- `[4,1,2,1,2]`：期望 4，对照第 6 节表格；
- `[1]`：期望 1，验证最小规模与单位元初值；
- `[0,1,0]`：期望 1，验证 0 参与异或不破坏结果；
- `[-1,-1,-2]`：期望 -2，验证负数在补码下性质仍成立。

调试切入点：打印每步的 `acc` 并与第 6 节表格比对；若结果错误，先确认数组是否严格满足"仅一个元素奇数次、其余偶数次"这一前提。可用哈希计数版作为 oracle 做随机差分测试。

## 8. 面试追问

1. **若其余元素都恰好出现三次（其余出现一次）？** 异或不再适用（三次不抵消）。改用逐位计数：对每个二进制位统计 1 的个数并对 3 取模，模 3 为 1 的位来自孤元素；时间 `O(32n)`、空间 `O(1)`。
2. **若有两个元素各出现一次、其余都出现两次？** 全异或得到 `x ^ y ≠ 0`。取 `x ^ y` 中任一为 1 的位 `mask`，用它把所有元素分成两组（该位为 0 / 为 1），`x` 与 `y` 必分属不同组，各组内部再跑一次异或即分别得到 `x` 和 `y`。
3. **若数组以流式到达且只允许一趟？** 本题异或法天然满足单趟、`O(1)` 空间；但要求输出顺序或涉及多元素奇偶统计时，单趟常数额外空间通常不可行。

## 9. 易错点与反例

- **反例**：试图用"求和再减去成对元素"求孤元素——当元素值重复但无法区分哪个成对时，减法无法定位孤元素，且对大数易溢出。
- **易错**：`acc` 初值写成 1，破坏单位元，结果整体被异或一个 1。
- **易错**：误以为"异或能处理任意出现次数"——只有偶数次（含成对出现）才抵消；出现三次时不成立。
- **易错**：混淆"出现两次"与"出现偶数次"的语义边界，在多孤元素变体里直接套用单趟异或。

## 10. 变体与迁移

- 同域迁移：出现三次的孤元素（逐位取模 3）、两个孤元素（分组异或）。
- 结构迁移：用异或求"缺失的数字"、找出数组中唯一不重复配对（异或亦可做两数交换 `a^=b^=a^=b`）。
- 约束迁移：一旦出现次数上限从 2 变为 3 或以上，"两次抵消"的前提失效，需切换到逐位计数或分组异或，时间与空间结论随之改变。
