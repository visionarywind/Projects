## 1. 题目与约束

给定包裹重量数组 `weights` 和天数 `days`，每天按顺序装载若干包裹，求能在 `days` 天内运完的最小船容量。

约束：`1 <= weights.size() <= 10^5`，重量为正数；必须保持原顺序。 本题采用标准约束，重点是把模式讲清楚并写出无明显边界错误的实现。

## 2. 面试思路

逐个尝试容量从最大单件到总和，范围可能很大，复杂度不可接受。

优化切入点：若容量 `C` 可行，则任何大于 `C` 的容量也可行；可行性关于容量单调，因此可以二分答案。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：左边界为最大单件重量，右边界为总重量。二分容量，用贪心扫描计算需要天数：当前天放不下就开新一天。若需要天数不超过 `days`，收缩右边界；否则增大左边界。

正确性说明：固定容量下，贪心每天尽量多装不会比提前换天使用更多天，因此能得到最少天数。可行性随容量增大单调不降，二分会保留最小可行容量所在区间，最终左右相遇即答案。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve(vector<int> weights, int days) {
    int left = 0;
    long long right = 0;
    for (int w : weights) { left = max(left, w); right += w; }
    auto needDays = [&](long long cap) {
        int used = 1;
        long long cur = 0;
        for (int w : weights) {
            if (cur + w > cap) { ++used; cur = 0; }
            cur += w;
        }
        return used;
    };
    long long l = left, r = right;
    while (l < r) {
        long long mid = l + (r - l) / 2;
        if (needDays(mid) <= days) r = mid;
        else l = mid + 1;
    }
    return (int)l;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

## 5. 复杂度

二分范围为总重量，检查 `O(n)`，总时间 `O(n log sum)`，空间 `O(1)`。 复杂度成立的前提是输入满足题目约束；如果输出本身很大，需要把输出规模计入空间和时间。

## 6. 例子推演

`weights=[1,2,3,1,1], days=4`。容量 3 时需 3 天? 实际按顺序分组为 `[1,2],[3],[1,1]`，3 天可行；更小容量 2 放不下重量 3，因此答案 3。
