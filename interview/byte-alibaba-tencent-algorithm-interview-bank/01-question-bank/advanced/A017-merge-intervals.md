## 1. 题目与约束

给定若干闭区间 `[l,r]`，合并所有重叠区间，返回互不重叠且按左端点升序排列的区间集合。

约束：`0 <= intervals.size() <= 10^5`；默认 `l <= r`。相邻区间是否合并需按题意，本题闭区间且重叠时合并。 本题按更高数据规模和工程可维护性要求处理，需要说明极端输入、常数因子和可测试性。

## 2. 面试思路

反复寻找可合并区间会导致多轮扫描，最坏接近 `O(n^2)`。

优化切入点：按左端点排序后，只需和结果中的最后一个区间比较；如果当前左端点不超过最后区间右端点，就能合并。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：先排序。遍历区间，若结果为空或当前区间与最后区间不重叠，则追加；否则更新最后区间右端点为两者最大值。

正确性说明：排序保证当前区间之后的区间左端点不小于当前左端点。若当前区间不能与结果最后区间重叠，也不可能与更早区间重叠；若能重叠，合并后的右端点取最大即可覆盖两者且不改变之前区间。归纳可知结果始终是已处理区间的正确合并。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> solve(vector<vector<int>> intervals) {
    sort(intervals.begin(), intervals.end());
    vector<vector<int>> ans;
    for (auto &seg : intervals) {
        if (ans.empty() || seg[0] > ans.back()[1]) ans.push_back(seg);
        else ans.back()[1] = max(ans.back()[1], seg[1]);
    }
    return ans;
}

int main() { return 0; }
```
