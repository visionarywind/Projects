## 1. 题目与约束

给定一个由字符 `'1'`（陆地）和 `'0'`（水）组成的二维网格 `grid`，统计**岛屿**的数量。岛屿由水平或垂直方向相邻的陆地连通而成，岛的四周被水包围；网格的四条边之外都视为水（即边界不连通到网格外）。

约束：`1 <= m, n <= 300`（`m` 行 `n` 列）；`grid[i][j]` 只取 `'0'` 或 `'1'`；只允许上下左右四个方向连通（不含对角线）；返回值为岛屿个数（`int`）。网格规模上限 `300×300 = 9·10^4` 个格子，递归 DFS 的深度最坏可达整个网格大小，需关注栈深度。

## 2. 面试思路

本质是**无向图的连通分量计数**：把每个 `'1'` 格子看作节点，相邻的 `'1'` 之间连一条边，答案就是图中连通分量的个数。

三种主流解法，面试时建议先说明"它们的时间复杂度都是 `O(mn)`，差别在空间、常数、以及是否修改输入"：

1. **DFS**：遇到未访问的陆地就作为新岛，从它出发把整块相连陆地标记掉，计数加一。代码最短，但递归深度最坏 `O(mn)`，`300×300` 时可能栈溢出。
2. **BFS**：用显式队列替代递归栈，空间可控、无栈溢出风险，适合大网格；代价是需要一个队列，且入队/出队有常数开销。
3. **并查集**：把相邻陆地 `union` 起来，最后统计不同集合根的数量（或初始把所有陆地各算一岛，每成功 `union` 一次就把答案减一）。适合"边动态加入"或需要反复查询连通性的场景。

面试表达顺序建议：**先定义图模型与连通分量目标 → 再对比三种实现的取舍 → 最后落地一种并讲清原地标记与边界处理**。

**关键工程考量**：访问标记可以额外开一个 `visited` 矩阵（`O(mn)` 额外空间），也可以**原地标记**（把访问过的 `'1'` 改成 `'0'` 或另一个字符，做到 `O(1)` 额外空间）。原地标记的代价是**会修改输入**，若后续还要复用原网格，必须先深拷贝或改用 `visited`。

## 3. 算法与正确性

以 BFS 版本为主线（避免栈溢出）。步骤：`ans = 0`；扫描每个格子 `(i,j)`：

1. 若 `grid[i][j] != '1'`，跳过；
2. 否则发现一座新岛，`++ans`，并启动一次 BFS：把 `(i,j)` 标记为已访问（原地置 `'0'`），入队；
3. BFS 循环：出队一个格子，检查其上下左右四个邻居，若邻居仍是 `'1'`，原地置 `'0'` 并入队。

四邻居方向用常量数组 `dirs = {{-1,0},{1,0},{0,-1},{0,1}}` 表示，边界判断统一为 `0 <= nr < m && 0 <= nc < n`。

**循环不变量**：外层扫描到第 `(i,j)` 个格子的第 1 步之前，恰好完成了 `[0, i) 全部行` 以及 `i` 行 `[0, j)` 列内所有陆地的连通分量归并，且这些区域的所有 `'1'` 都已被置 `'0'`。因此当 `(i,j)` 仍是 `'1'` 时，它必然属于一个尚未被计数的连通分量。

正确性：每次外层发现一个仍为 `'1'` 的格子，说明它所在的整块连通分量尚未被任何先前 BFS 覆盖（否则早被置 `'0'`）。一次 BFS 恰好访问且仅访问该分量的全部节点（连通性保证可达、置 `'0'` 保证不重复入队），故新岛计数加一恰对应一个新的连通分量。扫描结束时，答案是连通分量总数。

DFS 版本正确性相同，只是用递归栈替代队列；并查集版本正确性在于：对每条相邻陆地的边做 `union`，最终的集合划分与连通分量划分一致。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int numIslands(vector<vector<char>>& grid) {
    if (grid.empty() || grid[0].empty()) return 0;
    int m = grid.size(), n = grid[0].size();
    int ans = 0;
    const int dirs[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};
    queue<pair<int,int>> q;
    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (grid[i][j] != '1') continue;
            ++ans;                       // 发现新岛
            grid[i][j] = '0';            // 原地标记，O(1) 额外空间
            q.emplace(i, j);
            while (!q.empty()) {         // BFS 淹掉整块岛
                auto [r, c] = q.front(); q.pop();
                for (auto& d : dirs) {
                    int nr = r + d[0], nc = c + d[1];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                    if (grid[nr][nc] != '1') continue;
                    grid[nr][nc] = '0';
                    q.emplace(nr, nc);
                }
            }
        }
    }
    return ans;
}
```

实现细节：入队即标记（而非出队才标记），保证同一格子不会被多个邻居重复入队，队列规模上界为 `O(mn)`；`queue<pair<int,int>>` 在每个用例前清空（这里 BFS 结束后自然为空）；方向表用两维常量数组便于扩展为八方向或带权。若要保留原网格，把 `grid[i][j] = '0'` 换成对 `visited` 矩阵写 `true` 即可。

并查集版本的等价实现要点：

```cpp
// parent 大小 m*n，find 带路径压缩，union 按秩合并
// 初始：每个陆地自成一集合，ans = 陆地总数
// 遍历每格，只需向右、向下两个方向 union 邻居（避免重复）
// 每成功 union 一次（根不同），ans--
```

## 5. 复杂度

- 时间：`O(mn)`。每个格子最多被访问常数次——外层检查一次，BFS/DFS 中被标记后再不会被当作陆地重新处理；每条边（相邻陆地关系）也只被检查常数次。并查集版本若用路径压缩 + 按秩合并，`union/find` 近似 `O(1)`（反阿克曼函数 `α(mn)`），总时间仍是 `O(mn·α(mn))`，工程上视为 `O(mn)`。
- 空间：
  - BFS：队列最坏存 `O(mn)` 个坐标，即 `O(mn)`。
  - DFS（递归）：递归栈最坏 `O(mn)`（蛇形岛屿），这是它相对 BFS 的主要风险。
  - 并查集：`parent`/`rank` 数组 `O(mn)`。
  - 原地标记后，三者都不需要额外 `visited` 矩阵；整体额外空间 `O(mn)` 主要来自队列或并查集数组。
- 对比小结：三种解法时间同阶；DFS 空间最省（无需显式容器）但有栈溢出风险；BFS 空间可控、最稳；并查集常数略大但支持动态边。

## 6. 例子推演

网格：

```
1 1 0 0
1 0 0 1
0 0 1 1
```

三个岛：左上 `(0,0)-(0,1)-(1,0)` 连通；右上 `(1,3)`；下方 `(2,2)-(2,3)` 连通。

BFS 扫描过程（行优先）：

| 扫描到 | 值 | 动作 | 影响 |
|---|---|---|---|
| (0,0) | '1' | ans=1，BFS 淹掉 (0,0)(0,1)(1,0) | 这三格变 '0' |
| (0,1) | '0' | 跳过 | — |
| (0,2)(0,3) | '0' | 跳过 | — |
| (1,0) | '0' | 跳过（已被淹） | — |
| (1,3) | '1' | ans=2，BFS 淹掉 (1,3) | (1,3) 变 '0' |
| (2,2) | '1' | ans=3，BFS 淹掉 (2,2)(2,3) | 两格变 '0' |
| 其余 | '0' | 跳过 | — |

最终 `ans = 3`，与人工判断一致。注意 `(1,0)` 在扫描到它时已变成 `'0'`，验证了"原地标记 + 行优先扫描"不会重复计数。

退化样例：全 `'1'` 的 `m×n` 网格答案是 1（单次 BFS 覆盖全图）；全 `'0'` 答案是 0（无数岛屿）；单格 `[['1']]` 答案是 1。

## 7. 测试与调试

建议用例：
- 上例 `3×4` 网格：答案 3，验证多岛与对角不相连；
- 全 `'1'`、全 `'0'`、单格三种退化；
- 蛇形长岛（每行交替错位连接）在大网格下测试 DFS 是否栈溢出、BFS 是否正确；
- 边界贴边陆地块（如第一行全是 `'1'`），验证四邻居边界判断不越界产生越界访问；
- 含孤立单格岛散布的网格，验证 `ans` 计数不遗漏。

调试切入点：打印每轮 BFS 的起点与淹掉的坐标集合；用 BFS 版本作为 oracle 与并查集版本做随机网格差分测试；若答案偏大，优先怀疑"出队才标记"导致重复入队，或对角线被误判为连通；若答案偏小，优先怀疑边界判断写错（`<=` 与 `<` 混淆）漏掉贴边陆地。

## 8. 面试追问

1. **若改为求"最大岛屿面积"？** BFS/DFS 时改为累计当前分量的格子数（入队/递归时计数加一），用一个局部变量记录本块面积，全局维护最大值；时间、空间复杂度不变。也可与计数合并成一次遍历同时输出岛屿数与最大面积。
2. **若改为"封闭岛屿数量"（四面都被水完全包围、不接触网格边缘的岛屿）？** 关键技巧是**从边界反推**：先把所有与边缘相连的陆地"淹掉"（从四条边界的陆地出发做 BFS/DFS），剩下的陆地即为封闭区域，再数连通分量。复杂度仍是 `O(mn)`，但多一趟边界洪水填充，正确性论证从"直接计数"变为"先剔除接触边缘的分量"。
3. **并查集如何实现，复杂度为何近似线性？** 用路径压缩（`find` 时把沿途节点直接挂到根）+ 按秩/按大小合并（`union` 时矮树挂高树），使树高降至近常数，单次操作均摊 `O(α(n))`。建图时只对右、下两个邻居 `union` 即可避免重复边；初始把每个陆地自成一集合、`ans` 记陆地数，每成功合并一次 `ans--`，最终 `ans` 即岛数。

## 9. 易错点与反例

- **反例**：把对角线也当作连通。网格
  ```
  1 0
  0 1
  ```
  对角相邻但四方向不连通，正确答案是 2；若误加对角方向会得 1。
- **易错**：BFS 中"出队才标记"，导致同一陆地被多个邻居重复入队，队列膨胀并可能重复计数。
- **易错**：边界判断写成 `nr <= m` 之类的越界比较，或在访问 `grid[nr][nc]` 前未先判断范围，造成越界读。
- **易错**：原地标记修改了输入却假设网格保持不变；若题目要求网格只读，必须改用 `visited`，否则后续用例或调用方读到被破坏的数据。
- **易错**：DFS 递归在 `300×300` 蛇形岛上深度达 `9·10^4`，超出多数评测机默认栈，表现为运行时错误（段错误）而非逻辑错误。
- **易错**：并查集忘记路径压缩或按秩合并之一，最坏树高退化为 `O(mn)`，总复杂度恶化。

## 10. 变体与迁移

- 同域迁移：最大岛屿面积（计数改累加面积）、封闭岛屿（边界洪水预处理）、岛屿的周长（统计边界边数）、不同岛屿的数量（记录分量形状做规范化哈希）。
- 结构迁移：把"网格连通分量"抽象为"无向图连通分量"，同样的 DFS/BFS/并查集套路可迁移到"朋友圈数量"、"等式方程可满足性"（并查集）等题。
- 约束迁移：若陆地是**动态加入**的（在线加点查分量数），只有并查集能高效回答，静态 DFS/BFS 需反复重建；若网格极大，应优先选 BFS 或显式栈 DFS 避免爆栈。
- 维度迁移：三维体素连通分量、带权网格的最短路（叠加 Dijkstra/BFS 分层）都可复用本节的图建模与"原地标记"技巧。
