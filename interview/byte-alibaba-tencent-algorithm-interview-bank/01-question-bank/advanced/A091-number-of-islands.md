## 1. 题目与约束

给定由 `0` 和 `1` 组成的网格，`1` 表示陆地、`0` 表示水域，四方向相邻的陆地属于同一岛屿，返回岛屿数量。

约束：`m,n <= 300`；是否允许修改输入需先确认，本实现使用 visited，不修改原网格。 本题按更高数据规模和工程可维护性要求处理，需要说明极端输入、常数因子和可测试性。

## 2. 面试思路

对每个陆地都重复搜索会反复访问同一连通块，导致不必要的高复杂度。

优化切入点：每个尚未访问的陆地都是一个新连通块的入口；从入口 BFS/DFS 标记整座岛。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：遍历网格。遇到 `1` 且未访问，答案加一，并用队列 BFS 标记所有四方向连通的陆地。

正确性说明：BFS 从入口访问到的正是与入口四连通的全部陆地，因此一次搜索对应一座岛。已访问陆地不会再次开启新搜索，避免重复计数；任何岛至少有一个最先被遍历到的陆地，会被计数一次。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve(vector<vector<char>> grid) {
    if (grid.empty() || grid[0].empty()) return 0;
    int m = grid.size(), n = grid[0].size(), ans = 0;
    vector<vector<int>> vis(m, vector<int>(n, 0));
    int dr[4] = {1, -1, 0, 0};
    int dc[4] = {0, 0, 1, -1};
    for (int r = 0; r < m; ++r) for (int c = 0; c < n; ++c) {
        if (grid[r][c] != '1' || vis[r][c]) continue;
        ++ans;
        queue<pair<int,int>> q; q.push({r,c}); vis[r][c] = 1;
        while (!q.empty()) {
            auto [x,y] = q.front(); q.pop();
            for (int k = 0; k < 4; ++k) {
                int nx = x + dr[k], ny = y + dc[k];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (grid[nx][ny] == '1' && !vis[nx][ny]) { vis[nx][ny] = 1; q.push({nx,ny}); }
            }
        }
    }
    return ans;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。
