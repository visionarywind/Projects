## 1. 题目与约束

给定不含重复元素的整数数组 `nums`，返回所有可能的排列。

约束：`1 <= nums.size() <= 8`；输出规模为 `n!`，题目规模通常较小。 本题按更高数据规模和工程可维护性要求处理，需要说明极端输入、常数因子和可测试性。

## 2. 面试思路

排列本身就是指数/阶乘级输出，不能期望低于输出规模；关键是避免漏解和重复。

优化切入点：排列可以看作逐个位置选择尚未使用的元素，选择后进入下一层，回溯时撤销选择。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：维护路径 `path` 和使用标记 `used`。当路径长度等于 `n` 时加入答案；否则枚举所有未使用元素，选择、递归、撤销。

正确性说明：每条从根到叶的搜索路径选择了每个元素恰好一次，因此对应一个合法排列；任意合法排列都能按其元素顺序在搜索树中找到唯一一条路径，所以不漏不重。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> solve(vector<int> nums) {
    vector<vector<int>> ans;
    vector<int> path;
    vector<int> used(nums.size(), 0);
    function<void()> dfs = [&]() {
        if (path.size() == nums.size()) { ans.push_back(path); return; }
        for (int i = 0; i < (int)nums.size(); ++i) {
            if (used[i]) continue;
            used[i] = 1;
            path.push_back(nums[i]);
            dfs();
            path.pop_back();
            used[i] = 0;
        }
    };
    dfs();
    return ans;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

## 5. 复杂度

输出有 `n!` 个排列，每个复制长度 `n`，时间和结果空间均为 `O(n*n!)`，递归栈 `O(n)`。 复杂度成立的前提是输入满足题目约束；如果输出本身很大，需要把输出规模计入空间和时间。
