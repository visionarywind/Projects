## 1. 题目与约束

给定非空整数数组，除一个元素只出现一次外，其余元素均出现两次，找出只出现一次的元素。

约束：线性时间、常数额外空间；整数可为负数，异或按二进制位工作。 本题在标准约束上增加对边界、重复值、溢出或接口返回约定的讨论，面试中需要主动比较暴力解和优化解。

## 2. 面试思路

用哈希计数可在线性时间完成，但需要 `O(n)` 额外空间，不满足常数空间要求。

优化切入点：异或满足 `x ^ x = 0`、`x ^ 0 = x`，且交换结合；成对元素会相互抵消。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：初始化 `ans=0`，遍历数组执行 `ans ^= x`，最终 `ans` 即只出现一次的元素。

正确性说明：由于异或满足交换结合律，所有出现两次的数可以两两配对并抵消为 0，剩下的就是唯一出现一次的数。遍历顺序不影响结果。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve(vector<int> nums) {
    int ans = 0;
    for (int x : nums) ans ^= x;
    return ans;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

## 5. 复杂度
