## 1. 题目与约束

给定若干区间，每个区间表示为 `[start, end]`。合并所有**重叠或相邻**的区间，返回互不重叠的区间列表，并要求结果**按左端点升序**排列。

约束：`1 <= intervals.size() <= 10^4`；`0 <= start <= end <= 10^4`；端点为闭区间，两个区间"重叠"定义为 `next.start <= cur.end`（含边界相接，如 `[1,3]` 与 `[3,5]` 合并为 `[1,5]`）。返回 `vector<vector<int>>`。

多约束下的关键约定：输入**未排序**；输出必须有序；相接即算重叠（此约定与部分平台的半开区间定义不同，需与面试官确认）。

## 2. 面试思路

先看朴素解：反复两两检查是否有公共部分并合并，若发生合并则重来，最坏 `O(n^2)` 轮，每轮 `O(n)`，合计 `O(n^3)`，且实现易错。也可用并查集把相交区间聚簇，但建图本身 `O(n^2)`，得不偿失。

核心观察：**若把所有区间按左端点排序，则任意两个重叠区间在排序后必相邻或跨越一段，可以一趟线性扫描完成合并。** 排序打破了"哪个区间先开始"的不确定性，使合并只需与"当前正在累积的区间"比较。

排序键的选择：按**左端点**升序即可。按右端点排序不能直接一趟合并（一个晚开始但早结束的区间可能被跳过）。这是本题与"按结束时间贪心"（如区间调度）容易混淆之处：**求最大不相交集合按右端点排序；求合并区间按左端点排序。**

面试表达顺序建议：**先说明为何必须先排序 → 定义"当前待合并区间" → 用 `max(end)` 处理被包含区间 → 给出归纳式正确性证明**。

## 3. 算法与正确性

步骤：

1. 将 `intervals` 按 `start` 升序排序（`start` 相同则 `end` 升序，保证结果确定）。
2. 初始化结果数组，把第一个区间作为"当前区间" `cur`。
3. 依次处理后续区间 `it`：
   - 若 `it.start <= cur.end`，二者重叠或相接，更新 `cur.end = max(cur.end, it.end)`；
   - 否则两区间分离，把 `cur` 推入结果，令 `cur = it`。
4. 循环结束后把最后的 `cur` 推入结果。

**循环不变量**：处理完前 `k` 个（已排序）区间后，结果数组保存的是前 `k` 个区间的**完全合并结果且互不相交有序**，`cur` 是其中最后一个区间（可能还在吸收后续）。

**正确性证明**（归纳）：

- 基础：只处理一个区间时，结果就是它自身，成立。
- 归纳步骤：已排序保证 `it.start >= cur.start`。若 `it.start <= cur.end`，则 `it` 与 `cur` 在端点处相交或相接，两者必须合并；合并后右端点是 `max(cur.end, it.end)`——用 `max` 而非直接取 `it.end` 是必需的，因为 `it` 可能被 `cur` **完全包含**（如 `cur=[1,10]`、`it=[2,3]`），此时若取 `it.end` 会错误地缩小右界。若 `it.start > cur.end`，则 `it` 与 `cur` 分离，且由于排序，`it` 与结果中所有更早区间也分离，故可以安全封存 `cur`。归纳成立。

**为何只需与 `cur` 比较**：排序后 `it.start` 不小于任何已处理区间的 `start`；若 `it.start > cur.end`，而更早的区间右端点都不超过 `cur.end`（它们都已被并入 `cur`），则 `it` 不可能与更早区间重叠。因此无需回溯比较。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 return a[0] != b[0] ? a[0] < b[0] : a[1] < b[1];
             });
        vector<vector<int>> res;
        res.reserve(intervals.size());
        int curL = intervals[0][0], curR = intervals[0][1];
        for (int i = 1; i < (int)intervals.size(); ++i) {
            const auto& it = intervals[i];
            if (it[0] <= curR) {                 // 重叠或相接
                curR = max(curR, it[1]);         // max 处理被包含区间
            } else {                             // 分离，封存当前区间
                res.push_back({curL, curR});
                curL = it[0];
                curR = it[1];
            }
        }
        res.push_back({curL, curR});             // 封存最后一段
        return res;
    }
};
```

实现细节：用两个标量 `curL/curR` 而非在结果数组里就地修改，逻辑更清晰、也避免"取 `res.back()` 再改"的别名风险；`reserve` 预留容量减少扩容；排序比较函数显式写出，避免依赖 `vector` 的默认字典序（默认恰好等价，但显式更稳）。若不允许修改输入，先拷贝一份再排序。

## 5. 复杂度

- 时间：`O(n log n)`，由排序主导；扫描为 `O(n)`。
- 空间：输出最坏 `O(n)`；排序就地使用 `O(log n)` 栈空间（`std::sort` 为内省排序），除输出外额外辅助空间近似 `O(log n)`。
- 关键前提：区间端点比较是 `O(1)`；若区间数量动态增长或要求在流上在线合并，需换成平衡树/有序映射维护，复杂度结论不同。

## 6. 例子推演

`intervals = [[1,3],[2,6],[8,10],[15,18]]`（已给出为未排序，排序后不变）：

| i | it | cur | 判定 | 动作 |
|---|---|---|---|---|
| 0 | [1,3] | [1,3] | 初始 | cur=[1,3] |
| 1 | [2,6] | [1,3] | 2 ≤ 3 重叠 | cur=[1,max(3,6)]=[1,6] |
| 2 | [8,10] | [1,6] | 8 > 6 分离 | 存 [1,6]，cur=[8,10] |
| 3 | [15,18] | [8,10] | 15 > 10 分离 | 存 [8,10]，cur=[15,18] |
| 结束 | — | — | — | 存 [15,18] |

结果 `[[1,6],[8,10],[15,18]]`。

被包含区间的边界样例 `[[1,10],[2,3],[4,5]]`：

| i | it | cur | 判定 | 动作 |
|---|---|---|---|---|
| 1 | [2,3] | [1,10] | 2 ≤ 10 | cur=[1, max(10,3)]=[1,10] |
| 2 | [4,5] | [1,10] | 4 ≤ 10 | cur=[1, max(10,5)]=[1,10] |

结果 `[[1,10]]`。若此处误写成 `curR = it[1]`，会得到错误的 `[1,5]`。

相接样例 `[[1,3],[3,5]]`：`3 ≤ 3` 判定为重叠，合并为 `[1,5]`。

## 7. 测试与调试

建议用例：
- `[[1,3]]`：单区间，原样返回；
- `[[1,4],[4,5]]`：相接，合并为 `[1,5]`，验证边界 `<=`；
- `[[1,4],[2,3]]`：右侧被包含，验证 `max(curR, it[1])` 不缩小右界；
- `[[1,2],[3,4]]`：完全分离，返回两段，验证封存逻辑；
- `[[5,6],[1,2],[3,4]]`：输入乱序，验证排序必要性；
- `[[1,10],[2,3],[5,7]]`：多区间被包含，反复验证 `max`。

调试切入点：打印排序后序列与每一步的 `cur`；用"逐个区间与结果并集两两合并直到不动点"的 `O(n^2)` 朴素实现作为 oracle，随机生成小区间做差分测试。若区间端点可能做加法（如计算总覆盖长度），注意 `int` 溢出，改用 `long long`。

## 8. 面试追问

1. **把一个新区间插入到已排序且互不相交的区间列表中并合并？** 三阶段 `O(n)`：先跳过右端点 `< newStart` 的区间，再合并所有与新区间重叠的区间（不断扩张 `newStart=min`、`newEnd=max`），最后追加剩余区间。因为输入已有序，无需重新排序。边界：新区间落在最前/最后、被完全包含、与多个区间重叠。
2. **求任意时刻的区间最大重叠数（等价于会议室 II：最少需要多少间会议室）？** **扫描线**：把每个区间的 `start` 记为 `+1`、`end` 记为 `-1`（闭区间相接时需定义半开或把 `end+1` 作 `-1` 的时刻），按时刻排序后前缀和的最大值即为最大并发数；时间 `O(n log n)`。也可用**最小堆**按 `end` 排序维护正在使用的会议室，新会议开始时间大于堆顶结束时间时弹出，答案取堆大小峰值。
3. **求两个区间列表的交集？** 双指针：各自有序排序，比较 `[a1,a2]` 与 `[b1,b2]`，取 `lo=max(a1,b1) <= hi=min(a2,b2)` 时有交集 `[lo,hi]`；然后移动右端点较小的那个指针。时间 `O(m+n)`（排序后）。注意半开区间下交集判据是 `lo < hi`，闭区间是 `lo <= hi`，差一个等号。

## 9. 易错点与反例

- **反例**：合并时写 `curR = it[1]` 而非 `max(curR, it[1])`。`[[1,10],[2,3]]` 会错误得到 `[1,3]`，丢失 `[4,10]` 段。
- **反例**：忘记排序直接扫描。`[[5,6],[1,2]]` 会把本不相交的两段误合并或漏合并。
- **易错**：重叠判定写成 `<` 而非 `<=`，导致相接区间 `[[1,3],[3,5]]` 未合并。
- **易错**：循环结束后忘记把最后一个 `cur` 推入结果，`[[1,2],[3,4]]` 会丢失 `[3,4]`。
- **易错**：把"合并区间（按左端点排序）"与"区间调度选最多不重叠区间（按右端点排序）"的排序键混淆。
- **易错**：空输入未特判，`intervals[0]` 越界。

## 10. 变体与迁移

- 同域迁移：`插入区间`（利用已有有序性做 `O(n)` 三阶段）、`无重叠区间`/`用最少的箭引爆气球`（按右端点贪心，求最小删除/最少数目，与本题排序键相反）。
- 结构迁移：会议室 II（扫描线或最小堆求最大重叠数）、区间交集（双指针归并）、区间覆盖总长度（合并后求和，注意闭区间长度 `end-start+1` 与实数区间 `end-start` 的区别）。
- 约束迁移：一旦区间需要在**流式/在线**下维护合并结果，无法预先排序，需用 `std::map<int,int>` 按端点维护有序区间并可 `lower_bound` 定位相邻区间合并，单次插入 `O(log n)`。

**证据与来源：** `[已确认]` 按左端点排序 + 单次扫描的经典解法与 `O(n log n)` 时间、`O(n)` 输出空间结论（公开经典算法资料与 C++17 标准库 `sort` 行为）；`[推断]` 公司训练标签来自公开经验归纳；`[建议]` 面试表达顺序与差分测试策略；完整样例未在目标 OJ 运行，标记 `[待验证]`。
