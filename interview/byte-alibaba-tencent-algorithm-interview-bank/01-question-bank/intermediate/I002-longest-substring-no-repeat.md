## 1. 题目与约束

给定字符串 `s`，返回其中**不含重复字符的最长连续子串**的长度。子串要求连续，空串长度为 0。

约束：`0 <= s.length <= 10^5`；字符集按字节处理时可视为 ASCII（128）或扩展字节（256），若含多字节 Unicode 需按码点处理，本题默认按字节 `char` 处理；返回 `int`。

关键在于区分**子串（substring，连续）** 与**子序列（subsequence，不连续）**：若是子序列，答案退化为"不同字符种类数"，问题完全不同。

## 2. 面试思路

先评估朴素解：枚举所有子串 `O(n^2)` 个，对每个用集合判重，总计 `O(n^3)`；即使用"枚举左端点并向右扩展、遇重复停止"优化，最坏仍 `O(n^2)`（如 `"abcdef...xyz"` 每次扩展到底）。`n=10^5` 时不可接受。

观察窗口的**单调性**：当窗口 `[left, right]` 中出现重复字符时，只需让 `left` 向右移动到"不再包含重复"的最小位置，而无须回退 `right`。`right` 只增不减、`left` 只增不减，故总移动量为 `O(n)`。

`left` 的更新有两种等价实现：

- **逐步收缩**：维护窗口字符计数，遇重复时反复 `++left` 直到重复消除。每次 `left` 移动一步，实现直观，也是 `O(n)`。
- **跳跃更新**：用 `last[c]` 记录字符 `c` 最近出现的下标，遇重复时令 `left = max(left, last[s[right]] + 1)`，避免逐个右移。

两者复杂度同为摊还 `O(n)`，但跳跃版常数更小、代码更短，面试中更受青睐。下面采用跳跃版。

面试表达顺序建议：**先说明单调性为何成立 → 定义窗口不变量 → 说明 `max(left, ·)` 的必要性 → 证明每步候选即为最优**。

## 3. 算法与正确性

维护窗口 `[left, right]` 与数组 `last[256]`（初值全 `-1`）。

**循环不变量**：在处理 `right = r` 之前，`[left, r-1]` 内所有字符互不相同，且 `left` 是使 `[left, r-1]` 无重复的**最小**左端点。

步骤：对每个 `right`，设字符 `c = s[right]`、其上次出现位置 `p = last[c]`：

- 若 `p >= left`，说明 `c` 在当前窗口内已出现，必须把窗口左端收缩到 `p` 之后：`left = max(left, p + 1)`；
- 否则当前窗口无重复，`left` 不变；
- 更新 `last[c] = right`；
- 用 `right - left + 1` 更新答案。

**正确性证明**：

- 不变量维持：更新后 `[left, right]` 无重复。若 `p >= left`，新的 `left = p+1` 使 `s[p]` 被移出窗口，而 `(p, right)` 之间的字符本就与 `s[right]` 不同（否则会取更近的 `last`），故无重复；若 `p < left`，窗口新增字符 `c` 在窗口内未出现过，仍无重复。
- 最优性：对固定的右端点 `right`，任何含 `s[right]` 且无重复的窗口其左端点不可能小于当前 `left`，因为 `[left-1, right]` 会同时包含位置 `left-1` 与 `right` 的相同字符（当 `left = p+1` 时二者都是 `c`）。因此 `right - left + 1` 是**以 `right` 结尾的最长无重复子串长度**，取遍所有 `right` 的最大值即为全局最优。

`max(left, p + 1)` 中的 `max` 不可省：`p` 可能落在当前窗口左侧（历史重复但已滑出），此时若直接写 `left = p + 1` 会把窗口**左界回退**，重新引入已排除的重复字符。`"abba"` 即为典型：处理最后的 `a` 时 `last['a']=0` 已滑出窗口（当前 `left=2`），`left` 应保持 2 而非回退到 1。见第 6 节推演。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int lengthOfLongestSubstring(const string& s) {
        int last[256];
        fill(begin(last), end(last), -1);   // 记录每个字符最近出现的下标
        int best = 0, left = 0;
        for (int right = 0; right < (int)s.size(); ++right) {
            unsigned char c = (unsigned char)s[right];
            if (last[c] >= left) {           // 重复字符落在当前窗口内
                left = last[c] + 1;          // 收缩左界到重复点之后
            }
            last[c] = right;
            best = max(best, right - left + 1);
        }
        return best;
    }
};
```

实现细节：用定长数组 `last[256]` 而非 `unordered_map`，避免哈希开销；下标 `c` 强制转 `unsigned char`，防止 `char` 为有符号时出现负下标。若字符集是完整 Unicode，改用 `unordered_map<char32_t,int>` 并按码点迭代。因为 `left` 单调不减，无需 `max(left, last[c]+1)`——当 `last[c] < left` 时条件 `last[c] >= left` 为假，`left` 不动，效果与取 `max` 等价，这样写更简洁且不易出错。

## 5. 复杂度

- 时间：`O(n)`。`right` 从 0 到 `n-1` 各推进一次，`left` 单调不减、总推进量不超过 `n`，每次操作为 `O(1)`。
- 空间：`O(min(n, |Σ|))`，本题定长数组为 `O(256) = O(1)`；若用哈希表存实际出现的字符则最坏 `O(n)`。
- 关键前提：字符集规模为常数时数组方案空间 `O(1)`；若字符集随输入增长（如按码点），空间上界随之变化。

## 6. 例子推演

`s = "dvdf"`（答案 3，子串 `"vdf"`）：

| right | s[right] | last[·] 相关 | 条件 `last>=left` | left | 窗口 | 长度 |
|---|---|---|---|---|---|---|
| 0 | d | last[d]=-1 | 否 | 0 | d | 1 |
| 1 | v | last[v]=-1 | 否 | 0 | dv | 2 |
| 2 | d | last[d]=0 ≥ 0 | 是 | 1 | vd | 2 |
| 3 | f | last[f]=-1 | 否 | 1 | vdf | 3 |

注意 `right=3` 时 `left` 仍为 1（不是 2），窗口 `"vdf"` 长度 3。

`s = "abcabcbb"`（答案 3）：

| right | 字符 | left 变化 | 当前窗口 | 更新后 best |
|---|---|---|---|---|
| 0 | a | 0 | a | 1 |
| 1 | b | 0 | ab | 2 |
| 2 | c | 0 | abc | 3 |
| 3 | a | → 1 | bca | 3 |
| 4 | b | → 2 | cab | 3 |
| 5 | c | → 3 | abc | 3 |
| 6 | b | → 5 | cb | 3 |
| 7 | b | → 7 | b | 3 |

边界：`""` 循环不执行，返回 0；`"bbbbb"` 每次 `left` 前移一位，长度恒为 1。

## 7. 测试与调试

建议用例：
- `""`：空串，返回 0；
- `"bbbbb"`：全重复，返回 1；
- `"pwwkew"`：答案 3（`"wke"`，注意不是 `"pwke"`，后者是子序列）；
- `"dvdf"`：答案 3，专门验证 `left` 不会因已滑出的历史重复而跳过头；
- `"abcdef"`：无重复，返回长度本身；
- `" "`（单个空格）：返回 1，验证非字母字符；
- `"abba"`：答案 2，验证 `left` 单调不减（处理第二个 `a` 时不回退）。

调试切入点：每步打印 `left`、`right`、`last` 命中情况与当前窗口子串；用 `O(n^3)` 暴力（枚举所有子串 + `set` 判重）作为 oracle，随机生成小字母表字符串做差分测试，重点覆盖重复密集输入。

## 8. 面试追问

1. **至多包含 K 个不同字符的最长子串长度？** 改用 `count` 哈希表统计窗口内各字符频次，`right` 扩展时增加计数；当**不同字符数 > K** 时右移 `left` 并递减计数、计数归零则删除该键，收缩到种类数 ≤ K。答案取窗口最大长度。时间 `O(n)`，空间 `O(K)`。当 `K=1` 时退化为"最长同字符子串"。
2. **最多替换 K 个字符后得到的最长重复字符子串？** 仍是滑动窗口：维护窗口内出现次数最多的字符计数 `maxCount`，若 `(right-left+1) - maxCount > K` 说明窗口内需要替换的字符超过 `K`，右移 `left`。答案取窗口最大长度。注意 `maxCount` 只需单调不减（无需在收缩时下调）即可保持 `O(n)`，这是该题常见的证明要点。
3. **若要返回该子串本身而非长度？** 在更新 `best` 时同步记录 `bestL = left, bestR = right`，最后 `s.substr(bestL, bestR-bestL+1)` 返回，时间空间不变。若要求"字典序最小"或"最靠左"的最长解，需在长度相同时按额外规则取舍。

## 9. 易错点与反例

- **反例**：把"子串"误读为"子序列"。`"pwwkew"` 的最长子序列无重复为 `"pwke"` 长度 4，而正确的最长子串是 `"wke"` 长度 3。
- **反例**：`left` 更新时漏掉 `max`/条件判断，`"abba"` 处理最后 `a` 时若直接 `left = last['a']+1 = 1` 会把已滑出的 `a` 拉回窗口视野，配合后续可能得出错误长度或 `left` 越界。
- **易错**：用 `char` 直接作数组下标，`char` 为有符号时高位字节成负下标，越界访问。
- **易错**：忘记每次循环都更新 `last[c] = right`，导致后续判断用到过期位置。
- **易错**：仅在"发生重复"时才计算答案，或答案初值设为 1，导致空串返回 1。

## 10. 变体与迁移

- 同域迁移：`至多 K 个不同字符` 与 `替换后最长重复字符`（第 8 节两题），都是"窗口不变量 + 收缩条件"的同一模板，只是不变量从"无重复"换成"种类数 ≤ K"或"需替换数 ≤ K"。
- 结构迁移：最小覆盖子串、找到所有字母异位词、字符串的排列，均属"定长/变长滑窗 + 频次统计"，可复用窗口收缩的框架。
- 约束迁移：一旦要求"恰好 K 个"或"包含指定字符集合"，收缩条件改为等式约束，贪心收缩不再单调，可能需要更复杂的窗口或双指针配合统计。
