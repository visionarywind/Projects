## 1. 题目与约束

给定整数数组 `nums` 和整数 `k`，返回和为 `k` 的连续子数组个数。

约束：`1 <= nums.size() <= 2*10^5`；元素可为负数，因此不能依赖滑动窗口单调性。 本题在标准约束上增加对边界、重复值、溢出或接口返回约定的讨论，面试中需要主动比较暴力解和优化解。

## 2. 面试思路

枚举所有左右端点并求和是 `O(n^2)`；即使用前缀和快速求区间和，端点数量仍是平方级。

优化切入点：若当前位置前缀和为 `s`，要让某个历史位置之后到当前位置的子数组和为 `k`，历史前缀和必须是 `s-k`。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：维护哈希表 `cnt`，记录每个前缀和出现次数。初始 `cnt[0]=1`。遍历元素并更新前缀和 `s`，答案累加 `cnt[s-k]`，再执行 `cnt[s]++`。

正确性说明：任意和为 `k` 的子数组 `(l..r)` 满足 `prefix[r]-prefix[l-1]=k`。当遍历到 `r` 时，所有 `l-1` 的前缀和都已计入 `cnt`，算法正好把满足条件的历史前缀数量加到答案中；每个子数组按其右端点唯一计数一次。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

long long solve(vector<int> nums, int k) {
    unordered_map<long long, long long> cnt;
    cnt.reserve(nums.size() * 2 + 1);
    cnt[0] = 1;
    long long sum = 0, ans = 0;
    for (int x : nums) {
        sum += x;
        auto it = cnt.find(sum - k);
        if (it != cnt.end()) ans += it->second;
        cnt[sum]++;
    }
    return ans;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。

## 5. 复杂度

时间 `O(n)`，空间 `O(n)`，使用 `long long` 避免前缀和溢出。 复杂度成立的前提是输入满足题目约束；如果输出本身很大，需要把输出规模计入空间和时间。
