## 1. 题目与约束

每次可以爬 1 级或 2 级，给定 `n`，返回爬到第 `n` 级的不同方法数。

约束：`1 <= n <= 45` 时答案在 32 位整数内；更大输入需定义取模或大整数。 本题在标准约束上增加对边界、重复值、溢出或接口返回约定的讨论，面试中需要主动比较暴力解和优化解。

## 2. 面试思路

递归枚举所有走法会重复计算同一楼层的子问题，复杂度指数级。

优化切入点：到达第 `i` 级的最后一步只可能来自 `i-1` 或 `i-2`，因此方法数满足 Fibonacci 型递推。 面试表达时建议先说清楚状态含义，再说明为什么该状态足以覆盖所有答案。

## 3. 算法与正确性

算法步骤：令 `dp[i]` 为到第 `i` 级的方法数，`dp[1]=1, dp[2]=2`，转移为 `dp[i]=dp[i-1]+dp[i-2]`。只保留前两个状态。

正确性说明：最后一步长度为 1 和 2 的两类方案互斥且覆盖所有合法方案；去掉最后一步后分别对应到达 `i-1` 与 `i-2` 的任意合法方案，因此转移完备且无重复。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int solve(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; ++i) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}

int main() { return 0; }
```

实现细节：代码使用标准库容器，不依赖平台扩展；若题目平台要求类名 `Solution`，可把 `solve` 函数移动到对应类中。面试手写时优先保证边界清晰，再考虑微优化。
