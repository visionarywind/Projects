## 1. 题目与约束

给定只包含 `'('`、`')'`、`'['`、`']'`、`'{'`、`'}'` 的字符串 `s`，判断它是否是**有效括号串**。有效需同时满足三条：左括号必须用**同类型**的右括号闭合；右括号必须按**正确顺序**闭合；每个右括号都有对应的左括号。

约束：`1 <= s.length <= 10^4`；输入只含上述六种字符；空串在多数定义下视为有效（本题按非空约束，但实现须能处理空串）。返回类型为 `bool`。

与"只有一种括号"的入门版本相比，难点在于**类型必须匹配**：仅靠计数无法区分 `"([)]"` 这类交错错误。

## 2. 面试思路

先暴露朴素想法并说明为何不够：

- **计数法**：若只有一种括号，遍历时 `+1/-1`、任意前缀非负且总和为 0 即有效。但三种括号下计数独立，`"([)]"` 的计数完全平衡却是无效的，因此计数法**信息不足**。
- **区间 DP**：定义 `dp[i][j]` 表示子串 `s[i..j]` 是否有效，按长度递推，`O(n^2)` 时间与空间；对本题的上万规模属于过度设计。

正确切入点：右括号闭合的是**最近一个尚未匹配的左括号**，这正是 **LIFO（后进先出）** 语义，用**栈**直接建模。用一张映射表把右括号映射到应该出现的左括号，可让三类型统一处理、避免冗长 `if-else`。

面试表达顺序建议：**先说明计数法为何失效 → 引出 LIFO → 定义栈不变量 → 证明覆盖所有非法情形**。

## 3. 算法与正确性

步骤：从左向右扫描 `s`；遇到左括号压栈；遇到右括号时检查栈顶是否为对应的左括号：若不是（含栈空）立即返回 `false`，若是则弹栈。扫描结束后，栈必须为空。

**循环不变量**：处理完下标 `i` 之后，栈内自底向上恰好保存**所有尚未匹配的左括号**，且按它们在原串中出现的先后排列，栈顶是最近的一个。

**正确性证明**（对扫描位置做归纳）：

- 合法性充分性：若算法返回 `true`，则每个右括号弹出时都匹配了栈顶同类型左括号，说明存在"同类型、按序、成对"的配对，故 `s` 有效。
- 合法性必要性：若 `s` 有效，则任一右括号对应的左括号就是它前面最近未匹配的那个，算法弹出栈顶恰为此元素；归纳可知不会出现类型不符或栈空，且最终全部配平，栈为空，算法返回 `true`。
- 反例覆盖：交错串 `"([)]"` 扫描到 `')'` 时栈顶是 `'['`，类型不符立即返回 `false`，正确识别非法。

**先判空栈再取栈顶**是关键：`"("` 结尾不会因取栈顶而越界；`")"` 开头则立即判非法。

## 4. C++17 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    bool isValid(const string& s) {
        static const unordered_map<char, char> match = {
            {')', '('}, {']', '['}, {'}', '{'}
        };
        vector<char> st;                 // 用 vector 模拟栈，比 stack 更省
        st.reserve(s.size());
        for (char c : s) {
            auto it = match.find(c);
            if (it == match.end()) {     // 左括号
                st.push_back(c);
            } else {                     // 右括号
                if (st.empty() || st.back() != it->second) return false;
                st.pop_back();
            }
        }
        return st.empty();               // 左括号必须全部闭合
    }
};
```

实现细节：用 `vector` 而非 `std::stack`，`push_back/pop_back` 均摊 `O(1)` 且缓存友好；映射表设为 `static const` 只初始化一次；判断"是否右括号"用 `find` 是否命中，逻辑上等价于 `c == ')' || c == ']' || c == '}'`。若 OJ 只给裸函数，去掉 `class` 包装即可。

## 5. 复杂度

- 时间：`O(n)`，每个字符恰好入栈或出栈一次，映射查询平均 `O(1)`。
- 空间：`O(n)`，最坏全为左括号时栈高为 `n`；平均 `O(n)`。
- 关键前提：字符集固定为六种括号，映射表规模为常数，不随 `n` 增长。

## 6. 例子推演

`s = "([)]"`（非法）：

| i | 字符 | 动作 | 栈（底→顶） |
|---|---|---|---|
| 0 | `(` | 入栈 | `(` |
| 1 | `[` | 入栈 | `( [` |
| 2 | `)` | 期望 `(`，栈顶 `[` | 返回 false |

`s = "{[()]}"`（合法）：

| i | 字符 | 动作 | 栈（底→顶） |
|---|---|---|---|
| 0 | `{` | 入栈 | `{` |
| 1 | `[` | 入栈 | `{ [` |
| 2 | `(` | 入栈 | `{ [ (` |
| 3 | `)` | 匹配 `(`，弹出 | `{ [` |
| 4 | `]` | 匹配 `[`，弹出 | `{` |
| 5 | `}` | 匹配 `{`，弹出 | 空 |

边界：`")"` 首个字符即右括号且栈空，返回 `false`；`"("` 扫描结束栈非空，返回 `false`。

## 7. 测试与调试

建议用例：
- `""`：空串，按定义应有效；
- `"()[]{}"`：并列三种类型，验证映射表正确；
- `"([)]"`：交错类型，验证类型检查而不只是计数；
- `"}("`：首字符右括号，验证空栈保护；
- `"[({(())}[()])]"`：深层嵌套，验证最终栈空判定；
- `"(((("`：全左括号，验证结束时非空返回 false。

调试切入点：在中途打印当前栈内容与即将比较的字符；可写一个基于区间 DP 的 `O(n^3)` 暴力 oracle（对小 `n`），随机生成长度 ≤ 8 的括号串做差分测试。

## 8. 面试追问

1. **右括号可被通配符 `*` 替代（`*` 可当 `(`、`)` 或空串），如何判断有效？** 括号类型退化为单一类型。可用**区间 DP**：`dp[i][j]` 表示 `s[i..j]` 是否可有效，按长度枚举分割点并处理 `(`/`*` 与 `)`/`*` 配对，`O(n^3)`；更优做法是**贪心双指针**：维护未匹配左括号数的可行区间 `[low, high]`，遇 `(` 则两者 `+1`，遇 `)` 则两者 `-1`（`low` 截断到 0），遇 `*` 则 `low-1`、`high+1`，若 `high < 0` 立即失败，结束时 `low == 0` 即有效，时间 `O(n)`。
2. **最少添加多少个括号能使字符串有效？** 单次扫描即可：用计数器模拟栈，遇左括号 `+1`；遇右括号时若无未匹配左括号（计数为 0）则该右括号**必须补一个左括号**，否则 `-1`；扫描结束剩下的未匹配左括号数**各补一个右括号**。答案为两者之和，时间 `O(n)`、空间 `O(1)`。注意 `"())"` 需补 1 个 `(`，`"((("` 需补 3 个 `)`。
3. **若要返回所有无效括号的下标（删除使其有效）？** 用栈记录下标：遇左括号压其下标，遇右括号匹配则弹出、否则标记该下标；扫描后栈中剩余下标与被标记下标即为需删除的位置（LeetCode 301 的前置问题），时间 `O(n)`。

## 9. 易错点与反例

- **反例**：只统计三种括号数量是否各自平衡，`"([)]"` 会误判为有效——计数法在多种类型下失效。
- **反例**：误以为"前后对称/回文"才有效，`"()[]"` 对称性不强却有效，`"([)]"` 视觉对称却无效——判据是 LIFO 匹配而非形状对称。
- **易错**：右括号分支忘记判空栈，`")"` 会触发 `st.back()` 于空容器，未定义行为。
- **易错**：结束时只看"有没有报错"而不检查栈是否为空，`"("` 会被误判为有效。
- **易错**：把映射表方向写反（键为左括号），导致比较逻辑颠倒。

## 10. 变体与迁移

- 同域迁移：`20` 型多类型匹配 → `最长有效括号`（在无效处切分或用栈记录分界下标，`O(n)`）。
- 结构迁移：括号生成（回溯枚举合法序列）、移除无效括号（DFS + 去重或 BFS 分层）、最外层括号解析（栈深度归零即一段原语）。
- 约束迁移：一旦引入通配符或"至少/最少修改"这类最优化目标，纯栈判定不再足够，需要 DP 或计数贪心，复杂度结论需重新评估。
