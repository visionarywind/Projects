# 领域总览

## 范围

本题库覆盖大厂算法面试中常见的数组、字符串、链表、栈队列、树、堆、贪心、二分、图、动态规划、回溯、数学、位运算、高级数据结构、在线算法和综合编码题。题目以算法能力为主线，以字节/阿里/腾讯公开经验归纳出的岗位侧重点作为交叉标签。

## 目标读者

- 准备校招、社招、实习、转岗或技术面的大厂候选人；
- 希望系统补齐算法与数据结构短板的后端、客户端、算法、基础架构工程师；
- 希望训练面试表达、代码可靠性和追问应对能力的学习者。

## 先修知识

C++ 基础、STL 容器、递归、指针、复杂度分析、基本数学、离散结构和调试能力。缺少先修时先完成 B001–B020，并用每题的样例推演补齐心智模型。

## 排除项

- 不声称收录任何公司内部题库、保密真题或官方题单；
- 不覆盖机器学习模型面、系统设计面或 GPU kernel 面，除非题目本身是算法设计；
- 不把未经运行的代码或性能数据标为已确认。

## 公司标签解释

`字节`、`阿里`、`腾讯` 标签用于训练路线，不代表该题一定在对应公司出现。题库将公开经验归纳为：字节更强调高频编码、字符串/数组、搜索和快速追问；阿里更强调数据结构组合、工程约束和复杂度；腾讯更强调链表、树、图、缓存和综合实现。该归纳统一标为 `[推断]` 或 `[建议]`。
