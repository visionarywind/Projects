# 模式索引

按算法模式把 12 道题分组。同一道题可能出现在多个模式下（例如 A001 同时是“哈希”和“前缀和”）。每个模式给出识别信号、代表题与关键不变量，指向各题正文。

## 哈希（值 → 下标 / 值 → 次数）

- **识别信号**：需要“查找历史信息”并在平均 `O(1)` 内回答。
- **代表题**：
  - B001 两数之和：值 → 下标，回答“是否存在补数”，先查后插。
  - A001 和为 K 的子数组：值 → 次数，回答“有多少个历史前缀和等于 `pre-k`”，`cnt[0]=1`。
  - E002 TopK：值 → 频次，计数是所有堆/桶/选择方案的前置。
  - I001 有效括号：右括号 → 左括号的映射表，统一三类型处理。
- **关键不变量**：哈希表在扫描到当前下标时，恰好保存“更早出现”的信息。

## 动态规划（DP）

- **识别信号**：状态可由更小/前置状态推出，存在重叠子问题与无后效性。
- **代表题**：
  - B002 爬楼梯：`f(n)=f(n-1)+f(n-2)`，滚动变量压到 `O(1)` 空间。
  - I001 追问：通配符括号的区间 DP（见第 8 节）。
- **关键不变量**：第 `i` 轮开始时，变量恰为正确的前置状态。

## 位运算

- **识别信号**：只涉及成对/奇偶出现、掩码、无进位运算。
- **代表题**：B003 只出现一次的数字：`a^a=0, a^0=a`，全体异或；追问的两次孤元素分组异或与三次逐位取模。
- **关键前提**：异或的交换律与结合律保证可重排抵消。

## 栈

- **识别信号**：需要匹配“最近一个尚未处理的对象”，即 LIFO 语义。
- **代表题**：
  - I001 有效括号：右括号匹配栈顶同类型左括号，结束栈空。
  - I001 追问：返回无效括号下标，栈记录下标。
- **关键不变量**：栈内自底向上保存所有尚未匹配的左括号，栈顶最近。

## 滑动窗口（同向双指针）

- **识别信号**：求最长/最短连续区间，窗口状态可增量更新且约束可被收缩修复。
- **代表题**：
  - I002 最长无重复子串：`last[c]` + `left` 单调不减，`O(n)`。
  - I002 追问：至多 K 个不同字符、替换 K 个字符的最长重复字符。
- **关键前提**：`right` 只增不减、`left` 只增不减；含负数的“和”类问题不满足单调性（对照 A001）。

## 排序 + 贪心（区间）

- **识别信号**：输入无序、需要按某种键线性扫描合并/选择。
- **代表题**：
  - I003 合并区间：按**左端点**排序，合并时取 `max`。
  - I003 追问：最大重叠数用扫描线或最小堆。
- **关键区分**：合并区间按左端点排序；区间调度选最多不重叠按右端点排序（易混淆）。

## 前缀和

- **识别信号**：区间和/区间计数可写成两个前缀之差。
- **代表题**：
  - A001 和为 K 的子数组：`sum(i..j)=pre[j]-pre[i]=k`，配哈希计数。
  - A001 追问：同余（整除）与二维压维。
- **关键不变量**：`pre` 长度 `n+1`，`pre[0]=0` 对应空前缀。

## 图搜索（网格/连通分量）

- **识别信号**：把对象建成节点、相邻关系建成边，求连通性或可达性。
- **代表题**：
  - A002 岛屿数量：DFS/BFS/并查集三解法，原地标记，`O(mn)`。
  - A002 追问：最大面积、封闭岛屿（边界洪水填充）。
- **关键不变量**：一次搜索恰好访问一个连通分量的全部节点。

## 二分答案

- **识别信号**：存在“关于某个量单调”的可行性，问最小可行值或最大可行值。
- **代表题**：
  - A003 最小船载重量：对容量二分，`check(C)` 贪心模拟天数。
  - A003 追问：分割数组最大值最小、磁力球最大距离。
- **关键前提**：可行集合是后缀区间；`mid` 取法与分支必须自洽。

## 设计（哈希 + 链表）

- **识别信号**：要求所有操作均摊 `O(1)`，且需维护某种全局次序。
- **代表题**：
  - E001 LRU 缓存：哈希定位 + 双向链表维护新旧次序，`splice`/`moveToFront`。
  - E001 追问：LFU、TTL、分片并发。
- **关键不变量**：链表节点集合 = 哈希键集合，链表顺序 = 最近使用时间次序。

## 堆 / 选择

- **识别信号**：求前 k 大/最频繁，或动态维护极值。
- **代表题**：
  - E002 TopK：小顶堆（可增量）、计数桶（离线）、快速选择（离线最快）。
  - I003 追问：会议室 II 用最小堆维护结束时间。
- **关键权衡**：`k` 与不同元素数 `m` 的相对大小决定堆、桶还是选择。

## 回溯（搜索 + 剪枝）

- **识别信号**：求所有方案/路径，决策树可枚举，且输入规模小。
- **代表题**：
  - E003 全排列：`used` 数组 + 排序去重，或交换法；`next_permutation` 字典序。
  - E003 追问：第 K 个排列（阶乘进制）。
- **关键前提**：输出规模 `Θ(n·n!)` 即复杂度下界，优化只能“不输出全部”。
