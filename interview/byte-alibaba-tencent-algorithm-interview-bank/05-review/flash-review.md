# 快速复习

一页式复习卡：12 道题的一句话核心思路，加复杂度速查表。用于面试前一天扫读。复杂度均为题面约束下的结论，标 `[已确认]`；未在目标 OJ 逐例运行。

## 一句话核心思路

- **B001 两数之和**：扫描时用哈希表存“已扫描元素→下标”，查 `target - nums[i]` 是否存在；先查后插避免自配对。
- **B002 爬楼梯**：线性 DP，`f(n)=f(n-1)+f(n-2)`，只需滚动保留前两项，空间压到 `O(1)`。
- **B003 只出现一次的数字**：全体异或，成对元素抵消为 0，剩下孤元素。
- **I001 有效括号**：用栈做 LIFO 匹配，右括号必须匹配栈顶同类型左括号，结束时栈必须为空。
- **I002 最长无重复子串**：滑动窗口，`last[c]` 记录字符最近位置，重复时把 `left` 跳到 `last[c]+1`，`left` 单调不减。
- **I003 合并区间**：按左端点排序后单次扫描，与“当前区间”比较，重叠则 `cur.end = max(cur.end, it.end)`。
- **A001 和为 K 的子数组**：前缀和变形为 `pre[j]-pre[i]=k`，用哈希表统计历史前缀和出现次数；`cnt[0]=1`。
- **A002 岛屿数量**：网格连通分量计数，DFS/BFS 淹掉整块陆地或并查集合并相邻陆地。
- **A003 二分答案**：答案（容量）可行性与容量单调，对答案二分，`check(C)` 用 `O(n)` 贪心模拟所需天数。
- **E001 LRU 缓存**：哈希表 `key→节点` 提供 `O(1)` 定位，双向链表维护新旧次序，访问/插入把节点移到头部。
- **E002 数据流 TopK**：先哈希计数，再用小顶堆（可增量）、计数桶（离线）或快速选择（离线最快）取频率前 k。
- **E003 全排列**：回溯决策树，每层选一个未用元素；含重复元素时排序后用 `nums[i]==nums[i-1] && !used[i-1]` 去重。

## 边界数字备忘

- B002：`f(45)=1836311903 < 2^31-1`，入门版 `int` 安全；更大 `n` 需取模 + 矩阵快速幂。
- A002：`300×300=9·10^4` 格，递归 DFS 深度最坏等于格子数，注意爆栈。
- A003：`sum` 上界约 `2.5·10^7`，二分约 25 次；`n=5·10^4` 时总计约 `1.25·10^6` 次操作。
- E002：`k ≪ m` 时小顶堆最优；`k` 与 `m` 同阶时计数桶或排序更优。
- E003：`n=8` 得 40320 个排列，`n=12` 约 4.79 亿，输出不可承受。

## 一句话决定解法

- 找“历史补数/历史个数”→ 哈希（B001、A001）。
- 找“区间的某个极值/计数”，且状态单调 → 滑动窗口（I002），否则前缀和（A001）。
- 问“是否存在某个分界点”且可行性单调 → 二分答案（A003）。
- 需要在 `O(1)` 下“访问即改次序” → 哈希 + 双向链表（E001）。
- “前 k 大/最频繁” → 堆或选择（E002）。
- “全部方案/路径” → 回溯，下界由输出规模决定（E003）。
