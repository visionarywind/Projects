# 常见错误

按题汇总 12 道题的常见编码与边界错误。每条都对应各题“易错点与反例”一节的具体反例。状态：`[已确认]` 经典结论与静态分析；未在目标 OJ 逐例运行的部分标 `[待验证]`。

## 入门

### B001 两数之和（K01，哈希一次遍历）

- **先插后查**：先 `pos[nums[i]] = i` 再 `find(target - nums[i])`，`nums=[3], target=6` 时会与自己配对返回 `[0,0]`。必须先查后插。
- **键值写反**：把下标当键、值当值，返回元素值而非下标。键是 `nums[i]`，值是 `i`。
- **忘记 `reserve`/`max_load_factor`**：`n=10^5` 且哈希冲突时被常数卡超时，平均复杂度虽仍是 `O(n)`。

### B002 爬楼梯（K08，线性 DP）

- **基础情形错位**：写成 `f(1)=1, f(2)=1`，则 `f(3)=2`，整体少一位。正确是 `f(2)=2`。
- **循环起点错**：从 `i=1` 或 `i=2` 起跑导致 `a, b` 初值被重复累加；应从 `i=3` 起跑并令 `a=f(1), b=f(2)`。
- **把有序走法当组合**：套 `C(n,k)` 忽略顺序，导致 `n=3` 得 2 而非 3。

### B003 只出现一次的数字（K10，异或）

- **初值非 0**：`acc = 1` 破坏异或单位元，结果整体被异或 1。
- **误用出现次数**：只有偶数次出现才抵消，出现三次时异或失效，需逐位取模 3。
- **溢出类型**：元素为 64 位时仍用 `int` 累加，截断高位。

## 中等

### I001 有效括号（K03，栈）

- **右括号分支不判空栈**：`")"` 时对空 `vector` 调用 `back()`，未定义行为。必须先判空。
- **只看中途报错、不检查栈空**：`"("` 会因未闭合漏判，扫描结束必须要求栈为空。
- **映射表方向写反**：键写成左括号，比较逻辑颠倒，所有输入都失效。

### I002 最长无重复子串（K02，滑动窗口）

- **漏 `max`/条件判断**：`"abba"` 处理最后 `a` 时直接 `left = last[a]+1 = 1`，把已滑出的 `a` 拉回窗口。应用 `last[c] >= left` 判断或 `left = max(left, ...)`。
- **`char` 直接做下标**：有符号 `char` 的高位字节产生负下标越界，需转 `unsigned char`。
- **忘记更新 `last[c]`**：后续判断用到过期位置，窗口收缩错乱。

### I003 合并区间（K05，排序 + 扫描）

- **取 `it[1]` 而非 `max(curR, it[1])`**：`[[1,10],[2,3]]` 会错误得到 `[1,3]`，丢失 `[4,10]`。
- **重叠判定用 `<` 而非 `<=`**：相接区间 `[[1,3],[3,5]]` 不合并。
- **循环结束忘记封存最后一段**：`[[1,2],[3,4]]` 丢失 `[3,4]`。

## 高级

### A001 和为 K 的子数组（K01，前缀和 + 哈希）

- **漏 `cnt[0]=1`**：`nums=[1,1], k=2` 得 0 而非 1，漏掉以 0 开头的区间。
- **误用滑动窗口**：元素含负数时窗口和不单调，`nums=[1,-1,1], k=1` 会漏计。
- **先插后查 / 计数用 `int`**：前者把零长度伪区间计入（`k=0` 时虚高），后者在放大规模时溢出，应用 `long long`。

### A002 岛屿数量（K07，网格连通分量）

- **把对角线当连通**：`1 0 / 0 1` 正确答案是 2，误加对角方向会得 1。
- **BFS 出队才标记**：同一陆地被多个邻居重复入队，队列膨胀并可能重复计数。应入队即标记。
- **边界判断写错 / 原地标记副作用**：`nr <= m` 之类的越界比较导致越界读；原题要求只读网格时必须改用 `visited`。

### A003 二分答案（K06，最小船载重量）

- **可行分支写 `hi = mid - 1`**：`mid` 本身可能是答案，减一会跳过正确答案。
- **`mid` 与分支不自洽致死循环**：`mid=(lo+hi)/2` 配 `lo=mid` 在区间长 2 时死循环；偏左中值配 `hi=mid`，或偏右中值配 `lo=mid+1`，二者必须自洽。
- **下界设成 1 / `used` 初值为 0**：下界应是 `max(weights)`；`used` 至少为 1，`[10],1` 应得 `used=1`。

## 专家

### E001 LRU 缓存（K11，哈希 + 双向链表）

- **`put` 命中不 `moveToFront`**：`put(1,1);put(2,2);put(1,9);put(3,3)` 会错误淘汰 1 而非 2。
- **先插入再判断容量**：`capacity=1` 时把自己的新节点淘汰掉；应满员时先取 `tail->prev` 再插入。
- **`get` 返回值指针/删除无哨兵**：淘汰后节点被复用读到脏数据；删除头/尾时空指针崩溃。应先复制 `value` 并保留哨兵。

### E002 数据流 TopK 高频元素（K05，堆 / 桶 / 快速选择）

- **`nth_element` 比较方向写反**：`greater` 用成默认 `less`，取到最小的 k 个。
- **桶数组大小写成 `n`**：频率等于 n 时下标越界，应为 `n+1`。
- **在线堆不清理过期项**：堆里堆积同一 key 的旧频率快照，按旧频率错误淘汰。

### E003 全排列（K09，回溯）

- **去重条件漏 `!used[i-1]`**：写成 `if (i>0 && nums[i]==nums[i-1]) continue;`，`[1,1]` 会得不到任何排列。
- **`res` 存引用而非拷贝**：回溯后 `path` 被修改，结果全被污染。
- **第 K 个排列漏减一 / 阶乘用 `int`**：`k` 未转 0-based 整体偏移一位；`n>=13` 时阶乘用 `int` 溢出。
