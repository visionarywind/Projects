# 领域总览

## 定位

AI Agent 是由模型驱动、能够在运行时选择行动并根据环境反馈继续执行的系统。这里的“行动”可以是调用工具、检索知识、更新状态、请求人工确认或委派子任务。题库关注工程系统，而非把模型输出本身等同于 Agent。

## 核心边界

| 概念 | 核心特征 | 不应混淆 |
|---|---|---|
| 普通 LLM 调用 | 一次输入到一次输出 | 不自动拥有执行循环或外部副作用 |
| 确定性 workflow | 代码预先决定步骤和分支 | 不等于模型自主规划 |
| Agent | 模型在约束下选择下一步，循环读取 observation | 不等于无限自主或必然可靠 |
| Tool | 受控的外部能力，具有 schema、权限和执行语义 | 不是把任意 shell 暴露给模型 |
| Memory | 为未来决策保留的状态/经验 | 不等于所有历史消息 |
| RAG | 按查询获取外部知识并提供来源 | 不自动解决长期用户记忆 |

## 先修知识

Python/TypeScript 或同等编程能力；HTTP、JSON Schema、异步与并发、数据库和缓存、OAuth/权限、基本概率与统计；了解 LLM 消息、token、上下文窗口和 embedding。没有 Agent 经验时先完成 `AG-B001`–`AG-B005`。

## 端到端主线

请求进入后，runtime 建立 `run` 和租约，模型依据稳定的系统约束与当前 observation 选择文本回复、工具调用或终止；工具网关校验 schema、权限和预算，执行后以带 trace 的结果回传；runtime 更新状态、记忆和评估事件，直至成功、失败、取消、人工接管或预算耗尽。模型选择不是安全边界，真正的授权、网络出口和数据访问必须在执行侧强制执行。

## 版本与实验边界

本题库采用协议/标准/论文和公开框架文档作为资料基线，不锁定单一模型或框架。快速变化的模型 API、MCP、框架默认值、性能数字和安全效果必须注明版本并默认标为 `[待验证]`。未提供运行环境和凭据，因此实践章节只给可执行方案与 oracle。
