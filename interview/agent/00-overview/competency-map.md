# 能力地图

| 能力 ID | 能力 | 入门级 | 中等级 | 高级 | 专家级 |
|---|---|---|---|---|---|
| AG-C01 | 概念与边界辨析 | 定义 Agent、tool、memory | 解释组件关系 | 处理约束冲突 | 第一性原理判断是否需要 Agent |
| AG-C02 | 流程、状态与调用链 | 画最小 loop | 追踪完整 run | 处理并发、异步、恢复 | 定义不变量和状态机 |
| AG-C03 | 实现与协议阅读 | 写 schema/伪代码 | 设计接口和 focused test | 处理版本兼容 | 评审协议与变更影响 |
| AG-C04 | 测试与评估验证 | 单步 oracle | 轨迹回归 | 分层指标与统计 | 评估评估器本身 |
| AG-C05 | 性能、容量与成本 | 估算调用和 token | 建 baseline | 做容量/收益模型 | 推导上限和二阶影响 |
| AG-C06 | 故障、恢复与复盘 | 分类现象 | 最小复现 | 降级、回滚、补偿 | 把事故转为平台制度 |
| AG-C07 | 生产安全与治理 | 最小权限、日志 | 租户和审计 | 威胁模型、灰度、隔离 | 合规、残余风险和治理 |
| AG-C08 | 架构权衡与演进 | 选择简单方案 | 比较两种实现 | 迁移和扩展设计 | 设定停止标准和演进路线 |

每道题至少绑定一个能力 ID；高级和专家题应同时体现多个能力，但不得用能力标签代替推理、证据和验证。
