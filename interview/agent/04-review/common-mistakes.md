# 常见错误

| 错误 | 为什么不成立 | 应追问 |
|---|---|---|
| 把 Agent 当成更长的 prompt | 没有运行时决策、反馈和治理边界 | 谁授权工具，状态在哪里？ |
| 只校验模型输出 | 模型不是权限或业务事实来源 | 执行侧如何二次校验？ |
| 超时就重试 | 外部副作用可能已发生 | 能否查询或去重？ |
| 事件写入成功等于工具成功 | 两个系统的提交点不同 | UNKNOWN 怎么处理？ |
| 结果正确就发布 | 轨迹可能越权或泄露 | 工具和安全 oracle 是什么？ |
| 把检索命中当事实 | 索引可能过期、污染或越权 | 来源、时间和权限如何验证？ |
| 用 prompt 防注入 | 不可信内容可诱导模型，prompt 不是硬边界 | gateway、sandbox、出口在哪里？ |
| 多 Agent 多数投票即正确 | 共同错误和同源污染仍存在 | 来源核验和冲突保留呢？ |
| 只看平均延迟 | fan-out 和排队会放大尾延迟 | P95/P99 与预算如何约束？ |
| 只回滚模型版本 | tool/policy/index/runtime 也影响轨迹 | 如何固定完整 bundle？ |
