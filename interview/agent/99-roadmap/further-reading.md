# 延伸阅读

## 规范与工程文档

- [JSON Schema](https://json-schema.org/specification)：结构化参数契约；不等于授权。
- [Model Context Protocol](https://modelcontextprotocol.io/)：工具与上下文协议；具体实现需按版本核对。
- [OpenTelemetry](https://opentelemetry.io/docs/)：trace、span、属性和观测语义。
- [NIST AI RMF](https://www.nist.gov/itl/ai-risk-management-framework)：风险治理框架。
- [OWASP LLM Top 10](https://owasp.org/www-project-top-10-for-large-language-model-applications/)：常见应用安全风险。

## Agent 与评估研究

- [ReAct](https://arxiv.org/abs/2210.03629)：推理与行动交替的研究范式。
- [Toolformer](https://arxiv.org/abs/2302.04761)：模型学习调用工具的研究。
- [Reflexion](https://arxiv.org/abs/2303.11366)：语言反馈和自我改进范式。
- [AgentBench](https://arxiv.org/abs/2308.03688)：多环境 Agent 评估。
- [SWE-bench](https://arxiv.org/abs/2310.06770)：软件工程任务评估。
- [Anthropic: Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)：Agent 评估设计。

## 实践原则

阅读资料时记录访问日期、版本和具体证据；论文或官方指南支持的是方法/定义，不自动证明本地实现、性能或安全效果。真实实验结果需另行记录环境、输入、oracle 和日志。
