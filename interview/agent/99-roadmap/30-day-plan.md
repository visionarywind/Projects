# 30 天学习路线

| 周期 | 学习重点 | 输出 |
|---|---|---|
| 第 1–3 天 | Agent/workflow/chatbot 边界、术语、最小 loop | 画状态和消息序列 |
| 第 4–7 天 | schema、工具网关、错误分类、oracle | 写 fake tool 和分层测试 |
| 第 8–11 天 | 上下文、摘要、memory、RAG grounding | 设计来源/TTL/删除字段 |
| 第 12–15 天 | ReAct、plan-execute、DAG、多 Agent | 比较路径、预算和冲突合并 |
| 第 16–19 天 | durable execution、幂等、UNKNOWN、fencing | 编写故障注入矩阵 |
| 第 20–22 天 | 注入、SSRF、capability、审批、审计 | 画信任边界和响应流程 |
| 第 23–25 天 | 评估、回放、judge 校准、可观测性 | 建立 golden trace 与发布门 |
| 第 26–28 天 | 队列、并发、P95/P99、成本、扩缩 | 做容量估算和预算表 |
| 第 29 天 | 多租户平台、版本 bundle、灰度回滚 | 写系统设计答案 |
| 第 30 天 | 模拟面试与复盘 | 按专家清单补证据和缺口 |

所有实验按隔离 fixture 执行；没有实际运行的结果必须标 `[待验证]`。
