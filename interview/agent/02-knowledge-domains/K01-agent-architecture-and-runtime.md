# AG-K01 Agent 架构与运行时

## 核心问题
如何建立、推进、暂停、恢复和终止一次可解释的 Agent run。

## 先修与不变量
先修：消息 API、异步编程和状态机。关键不变量：每个 run 有唯一 ID；每个 step 有序且可关联；终态只提交一次；取消后不得继续产生未授权副作用；预算耗尽必须可观测。

## 题目索引
代表题目：AG-B001、AG-B002、AG-I001、AG-A001、AG-E001、AG-E004；完整索引见 `../00-overview/coverage-matrix.md`。

## 实践入口
实现内存版 loop，再加入持久化事件、取消、重放和崩溃恢复；运行结果需自定义 oracle。
