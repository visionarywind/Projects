# AG-K02 模型交互与上下文管理

## 核心问题
消息角色、token 预算、结构化输出和上下文压缩如何改变 Agent 行为。

## 先修与不变量
先修：LLM 基本调用、JSON Schema、序列化。关键不变量：系统约束与不可信 observation 分层；截断和摘要可追溯；结构化输出失败不能静默当作合法动作；上下文预算可计算。

## 题目索引
代表题目：AG-B004、AG-I003、AG-E002；完整索引见 `../00-overview/coverage-matrix.md`。

## 实践入口
对同一轨迹比较原始历史、摘要历史和丢失关键事实三种输入，验证事实保持率和 token 成本。
