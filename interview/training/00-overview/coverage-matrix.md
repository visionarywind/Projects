## 完整性规则

1. 每个稳定 ID 只出现一次，题目标题不得作为唯一身份。
2. 每题必须有难度、知识域、考察能力、题型、频率、前置知识、关联题目、事实状态。
3. 每个难度都要出现概念、原理、流程、实现、对比、测试、排障、性能、工程和开放题。
4. `U / 待验证` 证据不得写成“已验证”；GPU/NCCL/模型/多进程实验仅保留方案。
5. 自动审计应检查 ID 连续性、重复标题、字段集合、Markdown 空白和内部链接。
