首先，把 $n$ 的二进制从低到高第 $i$ 到 $j$ 位清除（置为 $0$），这里 $i$ 和 $j$ 都是从 $0$ 开始的。

如何清除二进制的比特位？

比如 $i=3$，$j=4$。

先构造一个二进制数 $11000$，然后将其取反，得到 $11\cdots1100111$。

然后计算 $n\ \operatorname{AND}\ 11\cdots1100111$。由于任何比特 $\operatorname{AND}\ 0$ 都等于 $0$，所以我们清除了第 $3$ 到 $4$ 位；由于任何比特 $\operatorname{AND}\ 1$ 都不变，所以其余比特不变。

如何构造 $11000$？

1. 构造 $100$，即 $1$ 左移 $j-i+1$。
2. 把 $100$ 减一，得到 $11$。
3. 把 $11$ 左移 $i$ 位，得到 $11000$。

然后把 $m$ 填入 $n$，$m$ 的最低位在第 $i$ 位。

做法是把 $m$ 左移 $i$ 后，与 $n$ 计算或。

```py [sol-Python3]
class Solution:
    def insertBits(self, n: int, m: int, i: int, j: int) -> int:
        # 清除 n 的从低到高 i~j 位（i 从 0 开始）
        n &= ~(((1 << (j - i + 1)) - 1) << i)
        # 把 m 填入 n
        return n | (m << i)
```

impl Solution {
    pub fn insert_bits(mut n: i32, m: i32, i: i32, j: i32) -> i32 {
        // 清除 n 的从低到高 i~j 位（i 从 0 开始）
