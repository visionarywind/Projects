## 思路

为方便双指针以及跳过相同元素，先把 $\textit{nums}$ 排序。

枚举 $\textit{nums}[i]$，问题变成 $\textit{nums}[j] + \textit{nums}[k] = -\textit{nums}[i]$，这和 [167. 两数之和 II - 输入有序数组](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/) 是一样的。

题目要求答案中不能有重复的三元组。如何避免重复？

在外层循环中，如果发现 $\textit{nums}[i] = \textit{nums}[i-1]$，那么 $\textit{nums}[i]$ 与后面两个数组成的和为 $0$ 的三元组，$\textit{nums}[i-1]$ 也能组成一模一样的三元组，这就重复了，所以遇到 $\textit{nums}[i] = \textit{nums}[i-1]$ 的情况，直接 $\texttt{continue}$。

在内层循环中，当三数之和等于 $0$ 时，为避免把相同的三元组计入答案，跳过后续相同的 $\textit{nums}[j]$ 和 $\textit{nums}[k]$（也可以只跳过相同的 $\textit{nums}[j]$）。

## 优化

**优化一**：如果 $\textit{nums}[i]$ 与后面最小的两个数相加 $\textit{nums}[i] + \textit{nums}[i+1] + \textit{nums}[i+2] > 0$，那么后面不可能存在三数之和等于 $0$，$\texttt{break}$ 外层循环。

**优化二**：如果 $\textit{nums}[i]$ 与后面最大的两个数相加 $\textit{nums}[i] + \textit{nums}[n-2] + \textit{nums}[n-1] < 0$，那么内层循环不可能存在三数之和等于 $0$，但继续枚举，$\textit{nums}[i]$ 可以变大，所以后面还有机会找到三数之和等于 $0$，$\texttt{continue}$ 外层循环。

## 写法一

```py [sol-Python3]
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        ans = []
        n = len(nums)
        for i in range(n - 2):
            x = nums[i]
            if i > 0 and x == nums[i - 1]:  # 跳过重复数字
                continue
            if x + nums[i + 1] + nums[i + 2] > 0:  # 优化一
                break
            if x + nums[-2] + nums[-1] < 0:  # 优化二
                continue
            j = i + 1
            k = n - 1
            while j < k:
                s = x + nums[j] + nums[k]
                if s > 0:
                    k -= 1
                elif s < 0:
                    j += 1
                else:  # 三数之和为 0
                    ans.append([x, nums[j], nums[k]])
                    j += 1
                    while j < k and nums[j] == nums[j - 1]:  # 跳过重复数字
                        j += 1
                    k -= 1
                    while k > j and nums[k] == nums[k + 1]:  # 跳过重复数字
                        k -= 1
        return ans
```

                }
            }
        }
        return ans;
    }

## 写法二

上面跳过重复数字的循环，也可以这样写：如果 $\textit{nums}[i] + \textit{nums}[j] + \textit{nums}[k] = 0$，并且 $j>i+1$ 且 $\textit{nums}[j] = \textit{nums}[j-1]$，则说明我们在之前找到了一样的三元组。

比如 $\textit{nums}=[-3,1,1,2,2]$，首先我们找到 $\textit{nums}[0] + \textit{nums}[1] + \textit{nums}[4] = 0$，在 $j$ 加一，$k$ 减一后，发现 $\textit{nums}[0] + \textit{nums}[2] + \textit{nums}[3]$ 也等于 $0$，但 $\textit{nums}[2] = \textit{nums}[1]$（这同时说明 $\textit{nums}[3] = \textit{nums}[4]$），是重复的三元组，不能加入答案。 

```py [sol-Python3]
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        ans = []
        n = len(nums)
        for i in range(n - 2):
            x = nums[i]
            if i > 0 and x == nums[i - 1]:  # 跳过重复数字
                continue
            if x + nums[i + 1] + nums[i + 2] > 0:  # 优化一
                break
            if x + nums[-2] + nums[-1] < 0:  # 优化二
                continue
            j = i + 1
            k = n - 1
            while j < k:
                s = x + nums[j] + nums[k]
                if s > 0:
                    k -= 1
                elif s < 0:
                    j += 1
                else:  # 三数之和为 0
                    # j = i+1 表示刚开始双指针，此时 j 左边没有数字
                    # nums[j] != nums[j-1] 说明与上一轮循环的三元组不同
                    if j == i + 1 or nums[j] != nums[j - 1]:
                        ans.append([x, nums[j], nums[k]])
                    j += 1
                    k -= 1
        return ans
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n^2)$，其中 $n$ 为 $\textit{nums}$ 的长度。排序 $\mathcal{O}(n\log n)$。外层循环枚举第一个数，就变成 [167. 两数之和 II - 输入有序数组](https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/solution/san-shu-zhi-he-bu-hui-xie-xiang-xiang-sh-6wbq/) 了，做法是 $\mathcal{O}(n)$ 双指针。所以总的时间复杂度为 $\mathcal{O}(n^2)$。
- 空间复杂度：$\mathcal{O}(1)$。返回值不计入。忽略排序的栈开销。
