# I05 Transformer 推理计算图

## 范围与定位

本域覆盖从 `ScheduleBatch` 到 `GenerationBatchResult` 之间的设备计算：`ForwardBatch.init_new`、`TpModelWorker.forward_batch_generation`、`ModelRunner.forward`、attention backend 选择、CUDA Graph replay/eager fallback、`ModelRunner.sample`、grammar/logits bias 处理、PP last rank logits 产出。与 I04 的边界在 `run_batch` 调用，与 I06 的边界在 prefill（extend）与 decode 的 `ForwardMode` 分叉。本域不处理 admission、KV 管理和进程拓扑。

## 核心概念与机制

**1. `ScheduleBatch` 与 `ForwardBatch` 是分离的快照**

`ForwardBatch.init_new`（`forward_batch_info.py:758-908`）明确声明不应修改输入 `ScheduleBatch`，读取 forward mode、batch size、`input_ids`、`req_pool_indices`、`seq_lens`、`out_cache_loc`、sampling metadata、LoRA ids、rids。对于 extend 模式，`extend_lens`、`prefix_lens` 和 logprob 起点被放入 forward metadata；decode/idle 时这些 extend-only 字段置为 `None`。设计原因：`ScheduleBatch` 可被 overlap 逻辑保存/恢复/更新，`ForwardBatch` 是当前 worker forward 所需的 device 输入，二者不能简单混为一个可任意原地修改的对象。[C: `01-modules/M05-model-execution/README.md:44-61`]

**2. TP worker 的三个执行分支**

`forward_batch_generation`（`tp_worker.py:1-564`）的分支：(1) dLLM 专用执行路径；(2) PP last rank 运行 forward 并拥有 logits；(3) 非 last rank 运行 forward 并把 proxy tensors 交给下一个 PP stage。普通 generation 路径：`ModelRunner.forward` → `logits_output` → `GenerationBatchResult` → 非 verify 且非 prefill-only 时 `ModelRunner.sample`。verify 模式跳过 sampling，因为 speculative worker 有自己的后续发布逻辑。prefill-only 请求创建与 batch size 对齐的 CPU/device dummy token，需要 input logprob 时调 `compute_logprobs_only`。[C: `01-modules/M05-model-execution/README.md:63-86`]

**3. CUDA Graph 不是"设置了 decode 就必然使用"**

`ModelRunner._forward_raw`（`model_runner.py:1756-1805`）首先判断当前模式和 decode CUDA Graph runner 是否允许 graph replay。可 replay 时直接执行 graph 并返回。不能 replay 时走 eager：DP/MLP-sync padding、attention-TP normalization、Mamba clear/COW，再进入 attention backend 的 eager forward。`can_run_graph` 的判断依赖 forward mode、runner 存在性和 `can_run(forward_batch)`。CUDA Graph runner 初始化时按 TP/CP、speculative、LoRA 和最大 batch 计算 capture batch 集合，创建固定形状 `DecodeInputBuffers`。`can_run()` 对动态 embedding 等输入直接返回 false。[C: `01-modules/M05-model-execution/README.md:87-100`; `90-cross-module/pooling-and-resource-management.md:110-118`]

**4. sampling 的 grammar mask 与 logits 处理**

`ModelRunner.sample`（`model_runner.py:1884-1938`）先清除 CUDA graph backing object 残留的 auxiliary output；按 observer 是否 active 选择 logits preprocessing。preprocess 更新 grammar vocab mask、应用 logits bias，立即释放 grammar mask GPU tensor，避免 overlap 延迟闭包持有它造成显存持续增长。sampler 接收：logits output、sampling info、是否返回 logprob、top logprobs 数量、token ids logprob 请求；decode 用 positions，prefill 用 `seq_lens - 1` 的最后位置。observer 处理采样结果，ngram embedding manager 更新 decode 状态。[C: `01-modules/M05-model-execution/README.md:101-117`]

**5. M05 出口是 `GenerationBatchResult`，不是用户文本**

`GenerationBatchResult` 可能包含 logits、next token ids、PP proxy、graph eligibility、expert/indexer auxiliary outputs。`Scheduler.process_batch_result` 根据 `ForwardMode` 选择 decode/prefill/prebuilt/idle processor，再把 token、finish、KV 和输出状态写回 `Req`。这条边界很重要：M05 不直接接触 `ReqState`、`BatchStrOutput` 或 HTTP 响应。[U: 具体模型 class 如何把 hidden states 变成 logits、不同 attention backend 的 KV layout 消费方式待逐模型追踪。][C: `01-modules/M05-model-execution/README.md:118-132`]

## 常见误区

1. **"CUDA Graph 总是用于 decode"** — 错误。graph replay 需同时满足 forward mode、runner 存在和 `can_run`，否则 eager fallback。[C: `01-modules/M05-model-execution/README.md:87-100`]
2. **"ForwardBatch 就是 ScheduleBatch"** — 错误。ForwardBatch 是从 ScheduleBatch 派生的 forward-only 快照，overlap 模式下原地修改会破坏并发正确性。[C: `01-modules/M05-model-execution/README.md:44-61`]
3. **"M05 负责写入 Req.output_ids"** — 错误。token 写入 `Req.output_ids` 是 `process_batch_result` 的职责，M05 只产出 `GenerationBatchResult`。[C: `01-modules/M05-model-execution/README.md:118-120`]
4. **"grammar mask 可以在采样后继续持有"** — 错误。代码立即释放以避免 overlap 延迟闭包造成显存持续增长。[C: `01-modules/M05-model-execution/README.md:104-106`]
5. **"prefill-only 请求也产生 decode token"** — 错误。prefill-only 只创建 dummy token，不进入正常 decode 路径。[C: `01-modules/M05-model-execution/README.md:83`]
6. **"CUDA Graph replay 失败会报错"** — 错误。`can_run_graph` 返回 false 时静默 fallback 到 eager，不抛异常。graph capture batch/shape/LoRA variant 不匹配时回退 eager。[U: 具体 fallback 路径的 coverage 测试分布待补。][C: `01-modules/M05-model-execution/README.md:97-100`]
7. **"overlap + grammar 下 sampling 立即同步完成"** — 错误。overlap + grammar 或 delay-sample 配置下 sampling 被包装成 `delay_sample_func`，由 scheduler 在结果处理时机执行，不是立即同步。[C: `01-modules/M05-model-execution/README.md:84-86`]
8. **"ModelRunner.forward 每次都重新创建 forward context"** — 错误。`forward` 先检查是否已有 forward context，再决定是否可 graph replay。`_forward_raw` 中先处理 DP/MLP-sync padding 和 attention-TP normalization，再执行 Mamba clear/COW。[U: 具体不同 attention backend 的 forward 差异待 M09 文档补全。][C: `01-modules/M05-model-execution/README.md:87-100`]
